# CloudFX → MT4 連携（予想レンジ・60%シグナル・最新終値マーカー）

毎朝GitHubへ記録しているFX/ゴールドの蓄積データから、**統計オーバーレイ**をMT4チャートに表示する仕組みです。

> ⚠️ **重要（価格の扱い）**
> ここで配信するのは「終値（概算）」と「統計パラメータ」であり、**発注に使う価格ではありません**。
> 実際の売買判断・約定価格は**MT4（ブローカー）のリアルタイム配信**を使ってください。
> このオーバーレイは「過去データから見た目安」を重ねるだけのものです。

---

## 構成

```
GitHub（毎日の自動更新で生成）
  fx/web/mt4_feed.csv  … 銘柄別の 最新終値 / 予想レンジ係数(μ,σ) / 60%シグナルの条件
        │  raw URL で公開（下記）。毎朝の push で自動更新。
        ▼
MT4（お手元PC）
  ① CloudFXFeed.mq4     … 取得役の EA。WebRequestでcsvを落とし MQL4\Files\ に保存。
  ② CloudFXOverlay.mq4  … 表示役のインジケータ。保存されたcsvを読み、チャートに描画。
```

- **EA（①）はネット取得専用**。UIを固まらせないため取得はEA側に寄せています。チャート1枚にだけ入れればOK。
- **インジケータ（②）はネットに触れません**。ローカルのcsvを読むだけなので、何枚のチャートにでも、売買EAと同居させても安全です。
- 予想レンジのラインと60%シグナルは、**ブローカーの実データ（D1）**を使ってMT4側でライブ計算します。フィードは「係数」と「ルール」を渡すだけです。

公開URL（EAの既定値に設定済み）:
```
https://raw.githubusercontent.com/doudemoee111-sys/todoapp_1/refs/heads/claude/cloud-business-automation-4kqckb/fx/web/mt4_feed.csv
```

## 導入手順

### 1. WebRequest を許可（1回だけ）
MT4 → **ツール > オプション > エキスパートアドバイザ** →
`次のURLリストに登録されたWebRequestを許可する` にチェックし、次を追加:
```
https://raw.githubusercontent.com
```

### 2. ファイルを配置
MT4 → **ファイル > データフォルダを開く** → `MQL4` フォルダ内へ:
- `CloudFXFeed.mq4`    → `MQL4\Experts\`
- `CloudFXOverlay.mq4` → `MQL4\Indicators\`

MetaEditorで両方を**コンパイル**（またはMT4再起動でナビゲータ更新）。

### 3. 取得役EAを起動
- 任意のチャート1枚に `CloudFXFeed` をドラッグ。
- ツールバーの **自動売買（AutoTrading）** をON。
- チャート左上に「更新OK 日時」と出れば成功（`MQL4\Files\cloudfx_feed.csv` が作られます）。
- 失敗時は「WebRequest許可」の設定（手順1）を見直してください。

### 4. 表示役インジケータを各チャートに適用
- 表示したい通貨ペアのチャート（**時間足は任意、計算はD1基準**）に `CloudFXOverlay` を適用。
- パラメータ:
  | 入力 | 意味 | 既定 |
  |---|---|---|
  | `InpSuffix` | ブローカーの銘柄サフィックス（例 `m`, `.pro`, `.raw`）。無ければ空欄 | （空） |
  | `InpGoldSymbol` | ゴールドの銘柄名（サフィックス前） | `XAUUSD` |
  | `InpMaxSigma` | 予想レンジを ±何σまで描くか（0〜3） | `2` |
  | `InpShowMean` | 平均(μ)ベースの予想高安も描く | `true` |
  | `InpShowClose` | 最新の概算終値マーカーを描く | `true` |
  | `InpShowSignal` | 60%シグナルを評価・描画 | `true` |
  | `InpAlert` | シグナル点灯時にアラート | `true` |

## 画面に出るもの

- **予想レンジ線**: 本日の始値（ブローカー値）を基準に
  - 予想高値 = 始値 + μ(高値−始値) + k·σ
  - 予想安値 = 始値 − ( μ(始値−安値) + k·σ )
  （k = 1,2,3。ダッシュボードの「本日の予想レンジ」と同じ計算式）
- **最新終値マーカー**（金色）: こちらが毎朝記録している概算終値と、その日付。
- **60%シグナル**: 終値ベースのN連続逆張り（例: 4連続陰線→翌日買い）のうち、
  **勝率60%以上・標本60件以上**を満たすものだけを対象に、
  ブローカーのD1終値で条件成立なら矢印＋アラート。チャート左上に勝率・標本数も表示。

## 注意・制限

- **終値は概算（WebSearchベース）**。約定価格には使わないこと。レンジ・シグナルは「目安」です。
- **銘柄名の違い**: ブローカーごとに `USDJPYm` などサフィックスが付きます。`InpSuffix`で調整。ゴールドは`InpGoldSymbol`で指定。
- **予想レンジの統計的注意**: 高値/安値ベースの係数(μ,σ)は、元データに始値=高値=安値=終値の「同値バー」が一定割合含まれるため、値幅がやや小さめに出る傾向があります（ダッシュボードと同じ特性）。レンジは“最低限の目安”として捉えてください。
- **シグナルの前提**: 過去の勝率であり将来を保証しません。特に円クロスの逆張りは相場環境（トレンド）に依存します。資金管理と併用してください。
- raw GitHub は数分キャッシュされますが、日次更新なので実用上問題ありません。
- フィードは毎朝の自動更新（`build_pages.mjs` が `mt4_feed.csv/json` を同時生成）で自動更新されます。手動更新は不要です。

## フィード仕様（`mt4_feed.csv`）

先頭行はコメント（`#`）。2行目がヘッダ。以降1銘柄1行:

| 列 | 内容 |
|---|---|
| `symbol` | USDJPY / EURJPY / GBPJPY / EURUSD / GBPUSD / GOLD |
| `date` | 最新営業日 |
| `close` | その日の概算終値 |
| `decimals` | 表示小数桁 |
| `mu` `su` | 高値−始値 の 平均・標準偏差 |
| `md` `sd` | 始値−安値 の 平均・標準偏差 |
| `n` | 統計に使った営業日数 |
| `sig` | シグナル方向（1=N連続下落→買い / -1=N連続上昇→売り / 0=無し） |
| `consec` | 連続本数 N |
| `winrate` | 過去勝率（0〜1） |
| `wins_n` | 標本数 |

JSON版も同じ内容で `fx/web/mt4_feed.json` に出力されます。
