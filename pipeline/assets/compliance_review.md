# 薬機法辞書の定期見直し記録

`compliance.py` の NG 辞書が **いまの法令に照らして正しいか** を確かめた記録。
公開済み動画の再チェック（`audit_published.py`）とは目的が違う。あちらは
「育った辞書に既存動画が追いついているか」、こちらは「辞書そのものが
古びていないか」を見る。

## なぜ四半期なのか

動くものが2つあり、速度がまるで違う。

- **法令**（薬機法・景表法・医療広告ガイドライン・ステマ規制）は年単位でしか
  動かない。毎月見るのは形式だけの作業になるが、まったく見なければ、動いた
  ことに気づかないまま非準拠になる。年単位で動くが動いた瞬間から効くものには
  四半期がちょうどよい。
- **こちらの死角**は速い。3週間で4回、辞書は「自分たちがすでに公開して
  しまった言い回し」を後追いで取り込んで育った。これは法令を読んでも
  見つからない。公開済みの側は `audit_published.py` が毎回自動で見るので、
  四半期の見直しでは **ゲートが書き換えた／削除した文** の傾向を読む。
  惜しくも通ってしまいそうだったものに、次の穴が出る。

`compliance.review_due()` が経過日数を見ており、90日を超えると毎回の実行ログに
警告が出る。四半期の定期実行（Routine）も同じ日数で回っている。

## 各回で確認すること

1. **法令・ガイドラインの更新**
   - 厚生労働省: 医薬品等適正広告基準、医療広告ガイドライン
   - 消費者庁: 景品表示法、ステルスマーケティング告示の運用基準
   - 機能性表示食品の届出制度（提携中の案件が該当する）
   - 変更があれば、該当する `NG_PATTERNS` と `writing_rules()` を直す
2. **こちらの死角**
   - 前四半期に `excise()` が削除した文と `rewrite()` が直した箇所を読む
   - 同じ型が繰り返し出ていれば、辞書に入れて「書かせない」側へ回す
3. **提携中のアフィリエイト案件**
   - `assets/affiliate_links.json` の `label` を現在の辞書で再チェック
   - 広告主のLPの訴求が変わっていないか（変われば見出しも直す）
4. **再走査** `python3 audit_published.py`（指摘0件であることを確認）
5. この表に1行追加して push する
