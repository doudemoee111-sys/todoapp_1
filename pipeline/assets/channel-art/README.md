## 設計方針

暗い寝室で深夜にスマホを開く視聴者が対象なので、**画面内で一番明るいものにしない**。
派手なサムネの定石とは逆に振っている。目が覚めてしまっては用途に反するため。

モチーフは**いびきの波形が平坦になり（無呼吸）、また再開する**線。
「隣で鳴っている音」の話だと一言も使わずに伝える図で、設計書・手順書と共通の記号。
中央のオレンジの線が無呼吸区間で、画面内で唯一の暖色。

## 守っている制約

- **バナーの安全領域**：YouTube は端末ごとに切り取り方が違い、中央 1235×338 だけが
  必ず見える。文字はすべてこの中に収めている（`generate.py` 実行時に検証可能）。
  波形は横幅いっぱいに伸ばしてあるので、テレビでは全体が、スマホでは無呼吸区間が
  ちょうど中央に見える。
- **アイコンの最小表示**：コメント欄では 24px まで縮む。月と波形を重ねると潰れるため
  上下に分離し、24px でも三日月と分かることを実寸で確認済み。

## 作り直すとき

```bash
pip install pillow
apt-get install -y fonts-noto-cjk     # Noto Sans CJK JP Bold を使用
python3 pipeline/assets/channel-art/generate.py
```

チャンネル名や更新曜日を変えた場合は `generate.py` の `make_banner()` 内の
`title` / `sub` / `meta` を編集して再生成する。
