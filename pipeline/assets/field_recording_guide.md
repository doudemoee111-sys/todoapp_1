# 実録音の録り方（1回20分）

長尺動画（L3）の音を、合成音から**実際に録った音**に替えるためのものです。
3分録れれば、こちらで継ぎ目の分からない2時間に伸ばします。

## なぜ替えるか

いまの2時間音源は、ffmpeg でノイズを合成して作っています。
著作権の心配が無く、何時間でも作れて、費用もゼロ。そこは優秀です。

ただ、**手続きで作ったものは、何本作っても互いに取り替えがききます。**
YouTubeの「本物でないコンテンツ」の判定は、機械が作ったかどうかではなく、
そこを見ています。8月のAI判定のあとで合成音の本数だけ増やすのは、
いちばんやってはいけない方向です。

**窓に当たる本物の雨は、定義上オリジナルです。** しかも安い。
スマホを窓際に20分置くだけで、2時間の動画1本の音になります。

## 録るもの（例）

| 音 | どこで | コツ |
|---|---|---|
| 雨が窓や屋根に当たる音 | 窓を少し開けて内側から | 強すぎる雨より、一定に降っている雨 |
| 川のせせらぎ | 近所の川・用水路 | 水面から1mほど離す |
| 波 | 海岸 | 風の音が勝ちやすいので風の弱い日に |
| 風が木を鳴らす音 | 公園 | マイクに直接風を当てない |
| 扇風機・換気扇の低い唸り | 自宅 | いちばん手軽。意外と使える |
| 深夜の雨上がりの水滴 | ベランダ | 間隔が空くぶん眠くなる音 |

## 手順

1. **スマホのボイスメモで、3〜10分録る。**
   機種は何でも構いません。使った機種名だけ控えてください。
2. **マイクに風を直接当てない。** 当たると「ボッ」という音が入り、
   これは後から消せません。タオルやハンカチを軽く巻くだけで変わります。
3. **録ったら、必ず最初から最後まで聴き返す。** これがいちばん大事です。
   - テレビ・ラジオ・音楽・人の話し声が入っていないか
   - 急に大きな音（車のクラクション、ドアの開閉）が入っていないか

   **音楽やテレビが入っていると、2時間動画に著作権の申立てがつき、
   その動画の収益は全部持っていかれます。** 入っていたら、その部分を外すか録り直してください。
4. **ファイルを私に渡してください。** この会話に添付でも、Googleドライブでも構いません。
   `pipeline/assets/field/` への配置と台帳への登録はこちらでやります。
5. 一緒に、次の4つだけ教えてください。
   - 録った日
   - 何の音か
   - どこで録ったか（部屋の向き、川の名前など。住所は不要です）
   - 何で録ったか（機種名）

この4つは、そのまま概要欄に載ります。**載ることが目的です。**
「2026年10月11日、自宅ベランダで iPhone 13 で録りました」と書いてある動画は、
どこからか持ってきた音を使った動画と、見た人にも審査にも区別がつきます。

## やってはいけないこと

- **フリー音源サイトの音を「実録音」として登録しない。** 嘘になりますし、
  同じ音源を使った動画が何千本もあるので、むしろ逆効果です。
- **他人の家の中、人の話し声、子どもの声を録らない。**
- **住所や家の外観が分かる情報を書かない。**
