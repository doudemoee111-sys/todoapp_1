# 実録音の置き場

ここに音源ファイルを置き、`../field_recordings.json` に登録してください。
録り方は `../field_recording_guide.md` にあります。

- 形式: m4a / mp3 / wav のいずれでも構いません（ffmpeg が読めれば何でも）
- 長さ: **3分以上**。2分未満は使えません（繰り返しが聞こえます）
- 大きさ: リポジトリに入るので、**1ファイル10MB以内**を目安に。
  長く録れたときは、いちばん素直な3〜5分を切り出してください。
  m4a の 96kbps なら 5分で約3.6MB です。

ここから2時間の音源を作ります。3分の録音が、継ぎ目の分からない2時間になります。
