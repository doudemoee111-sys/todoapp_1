# 実測データの出し方（週1回・15分）

このチャンネルで、私（自動化）に作れないものは1つだけです。**実際に測った数字。**
ここに1件入れていただければ、残りは全部こちらで動画にします。

8月にYouTubeからAI判定を受けた理由は、たぶん「機械が作ったから」ではなく、
**「どの動画も、他のどの動画と取り替えても成立するから」** です。
測った数字は取り替えがききません。日付があり、場所があり、機材があり、
視聴者が自分の家で確かめられる。これが入っているだけで、動画の立場が変わります。

---

## 1回の手順

### ① 測るものを1つ決める

その週の切り口に合うものを、こちらから毎週お伝えします。
思いつくものがあれば、それを優先してください。何でも構いません。

よくある例:

| 測るもの | 要るもの | かかる時間 |
|---|---|---|
| 寝室の騒音（深夜） | 騒音計アプリ（無料） | 置いて寝るだけ |
| 耳栓あり / なしの差 | 騒音計アプリ＋耳栓 | 2晩 |
| 寝室の温度・湿度の朝までの変化 | 温湿度計（1,500円〜） | 置いて寝るだけ |
| 常夜灯・街灯の明るさ | 照度計アプリ（無料） | 3分 |
| 遮光カーテンを閉めたときの明るさ | 照度計アプリ | 3分 |
| 枕の高さ（仰向け / 横向き） | メジャー | 5分 |
| マットレスの沈み込み | メジャー＋定規 | 5分 |
| 加湿器・空気清浄機の運転音 | 騒音計アプリ | 5分 |
| ベッドまわりの寸法 | メジャー | 5分 |

**スマホのアプリで足ります。** 校正されていないので絶対値は信用できませんが、
**同じ機材・同じ位置で測った「差」** は十分に意味があります。
そのことは毎回、概要欄に明記します。

### ② 測る

大事なのは、**次に測るとき同じ条件で測れるように書き留めること**だけです。

- 何時に測ったか
- どこに置いたか（枕元から30cm、など）
- 窓やドアは開いていたか
- 何で測ったか（アプリ名・機種名）

### ③ 書く

`pipeline/assets/measurements.json` の `records` に1つ足してください。
記入例（`example-DO-NOT-USE`）をコピーして書き換えるのがいちばん早いです。

```json
{
  "id": "2026-10-06-earplug",
  "date": "2026-10-06",
  "subject": "何を測ったか",
  "where": "どこで（部屋の広さ・階数・窓の向きまで書くと強い）",
  "device": "何で測ったか（アプリ名・機種名）",
  "method": "どう測ったか（位置・時間帯・間隔）",
  "readings": [
    {"label": "項目名", "value": "42 dB"}
  ],
  "finding": "測って分かったこと。あなたの言葉で1〜2文。",
  "limits": "この測定では分からないこと。",
  "ready": true,
  "used_in": []
}
```

**書くのが面倒なら、この会話に数字をそのまま貼ってください。**
JSONはこちらで書きます。必要なのは上の①②だけです。

---

## いちばん大事な2つの欄

`readings` の数字と同じくらい、この2つが効きます。

**`finding`（測って分かったこと）** — ここはあなたの言葉です。
「11デシベル下がったが、下がったのは高い音だけだった」のような、
**測った人にしか書けない一文**を入れてください。きれいにまとめなくて構いません。
うまくいかなかった、よく分からなかった、でも構いません。
むしろそのほうが、この動画が本物である証拠になります。

**`limits`（分からないこと）** — ここを書くチャンネルはほとんどありません。
だから書きます。「アプリの騒音計は校正されていないので絶対値は信用できない」
のように、自分の測定の弱点を先に言う。これは信頼になりますし、
薬機法の観点でも、数値を効果の根拠にしない歯止めになります。

---

## やってはいけないこと

- **測っていない数字を書かない。** ネットで見た平均値、推定値、一般的な目安。
  これを入れた瞬間、このジャンルに切り替えた意味が消えます。
  パイプラインは数値を作りませんし、空欄なら「測定なしの回」として作ります。
- **体への効果を書かない。** 「これで眠りが深くなった」は薬機法で止まります。
  測ったのは部屋とモノです。体のことは書かなくて大丈夫です。
- **個人や住所が分かるものを写さない・書かない。**

---

## 在庫が切れたとき

0件になると、実行前のチェックで警告が出て、私からもお知らせします。
**そのときも投稿は止めません。** 測定なしの回として作り、記録にそう残します。
ただし、それが続くなら、このジャンルに切り替えた意味がなくなります。
**在庫は2件以上を目安**にしてください（週1本なら2週間分です）。
