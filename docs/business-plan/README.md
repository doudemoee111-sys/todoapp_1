# 副業ビジネス提案 一覧

調査・分析：Claude Code

## 前提条件（全提案に共通）

1. AI活用（自動化でき、従業員不在で運営できる）
2. 年商1億円以上が望めるマーケット
3. 成功事例に基づき、3か月以内に軌道に乗りやすい
4. 初期投資を抑えられる
5. この数年で伸びており、今後も期待できるジャンル

## 提案②：訪日外国人向け AI旅程＆予約アシスタント — **BtoC**

📁 [`proposal-02-inbound-ai-concierge/`](./proposal-02-inbound-ai-concierge/)

訪日外国人向けに「実際に行ける・予約できる日本旅行プラン」をAIが自動生成して直接販売する完全デジタルのD2C。**既に1件$120〜$400の人力コンシェルジュが成立している市場**を、AIで無人化して$39で取りに行く。商談ゼロ・在庫ゼロ・接客ゼロ。

| 市場 | 訪日消費額 9兆4,549億円（+16.4%）／政府目標 2030年 15兆円 |

## 2案の比較

| | 提案①（BtoB） | 提案②（BtoC） |
|---|---|---|
| 初売上まで | **4〜6週間** | 7〜8週間 |
| 3か月時点の月商 | **50〜100万円** | 12〜20万円 |
| 収益の性質 | **ストック（積み上がる）** | フロー（毎回集客が要る） |
| 営業 | 商談が必要（人が出る） | **不要（完全セルフサーブ）** |
| 無人化の徹底度 | 商談だけ人が残る | **完全無人が可能** |
| 市場成長率 | AI市場 CAGR 36% | インバウンド +16.4% |
| 最大リスク | AI事業者の規約／競合40社超 | 旅行業法／ハルシネーション実害 |

**早く現金がほしい・人と話すのが苦でない → 提案①。**
**人と一切話さず完結させたい → 提案②。**

両者は併走できる。提案①で身につけるAI検索最適化の技術は、そのまま提案②の集客エンジンになる（詳細は[提案② §6](./proposal-02-inbound-ai-concierge/README.md)）。
