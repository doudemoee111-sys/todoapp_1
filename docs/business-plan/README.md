# 副業ビジネス提案 一覧

調査・分析：Claude Code

## 前提条件（全提案に共通）

1. AI活用（自動化でき、従業員不在で運営できる）
2. 年商1億円以上が望めるマーケット
3. 成功事例に基づき、3か月以内に軌道に乗りやすい
4. 初期投資を抑えられる
5. この数年で伸びており、今後も期待できるジャンル

## 提案③：経験者マイクロ相談マーケット — **CtoC**

📁 [`proposal-03-experience-marketplace/`](./proposal-03-experience-marketplace/)

「AIが答えられないこと」だけを売るCtoC。特定のライフイベントを通過した個人が、これから通る個人に15〜60分だけ経験を売る場をつくり、マッチング・事前質問生成・事後要約をAIが全自動で回す。AIが一般知識を無料化した結果、**個人の生々しい一次情報の相対価値が上がっている**という構造変化が追い風。

| | |
|---|---|
| 顧客 | 一般個人 ↔ 一般個人（運営は手数料のみ） |
| 単価 | 3,000〜11,000円／件（手数料25%） |
| 初期投資 | 3か月累計 29万1,000円 |
| 3か月時点 | 月商 5〜10万円 |
| 市場 | シェアリングエコノミー 2.4兆円 → 2030年度 14.2兆円（CAGR 19.6%） |
| 難易度 | **3案で最も高い**（鶏と卵・資格法） |

## 提案④：越境EC輸出（個人・物販） — **壁打ち用の検証レポート**

📁 [`proposal-04-cross-border-export/`](./proposal-04-cross-border-export/)

日本のリユース品・国産新品を海外へ輸出販売する案。「年商6,000万円・利益率20%は可能か」という問いへの検証が主目的で、**提案①〜③とは性質が異なり、在庫と物理作業を伴う物販**です。

| | |
|---|---|
| 年商6,000万円 | **可能**（単価3万円 × 年2,000件 ＝ 1日5.5件の出荷） |
| 利益率20% | **条件付きで可能**（消費税還付＋米国依存の回避＋仕入倍率2.3倍） |
| 半自動化 | **リサーチ→出品→ラベル発行まで可能。梱包・発送だけ残る** |
| 推奨の出店先 | **eBay（主軸）＋ Shopee（サブ）** |
| 初期投資 | **運転資金 200〜250万円**（＋諸費用24万円） |
| 市場 | 世界の越境EC 1.01兆USドル／CAGR 23.1% |

> ⚠️ 当初5条件のうち「従業員不在」と「初期投資が低い」は**×**です。一方で**既存プラットフォームを使うため集客が不要で、初売上は4案中もっとも早い**可能性があります。
> ⚠️ **米国の関税制度がこの半年で3回変わりました**（de minimis廃止 → 最高裁の違法判決 → 通商法122条 → 301条／現在は対日12.5%）。利益率の成否は商品選定よりここで決まります。

> ⚠️ **無在庫（ドロップシッピング）で価格差を自動抽出するモデルは推奨しません。** ツール層が既にコモディティ化しており、かつeBay・メルカリ双方の規約が小売直送を禁じているため自宅経由が必須になります。加えて**無在庫では中古品を扱えず、日本セラー最大の武器（中古が売上の6割・単価2.3倍）を捨てることになります**。詳細と差別化の5軸は補論を参照。

## 4案の比較

| | **①** BtoB | **②** BtoC | **③** CtoC | **④** 越境EC輸出 |
|---|---|---|---|---|
| 事業 | AI検索可視化 | 訪日AI旅程 | 経験者マイクロ相談 | リユース・国産品の輸出 |
| 在庫 | なし | なし | なし | **あり** |
| 初売上まで | 4〜6週間 | 7〜8週間 | 8〜10週間 | **3〜5週間** |
| 3か月時点の月商 | **50〜100万円** | 12〜20万円 | 5〜10万円 | 30〜80万円（仕入次第） |
| 収益の性質 | ストック | フロー | プラットフォーム | フロー（在庫回転） |
| 従業員不在 | ○（商談は残る） | **◎（完全無人）** | △（トラブル対応） | **×（梱包・発送）** |
| 初期投資 | **23.4万円** | 26.9万円 | 29.1万円 | **224〜274万円** |
| 集客の必要性 | あり | あり | あり（両面） | **なし（モールが集客）** |
| 最大リスク | AI事業者の規約／競合40社超 | 旅行業法／ハルシネーション | 鶏と卵／資格法 | **関税制度の流動性／在庫** |
| 難易度 | **低** | 中 | 高 | 中（ただし資金が要る） |

### 選び方

- **確実性と速度、そして低資本を取るなら 提案①。** 4案で唯一、当初5条件すべてに◎で応える。
- **人と一切話さず完結させたいなら 提案②。** ただし旅行業法の確認に時間を要する。
- **時間はかかっても、労働から切り離された資産を作りたいなら 提案③。** 失敗確率も最も高い。
- **手元資金が200万円以上あり、体を動かすことを厭わないなら 提案④。** 集客が不要なぶん初売上が最も早い。

**提案①〜③と④は排他ではありません。** ④は在庫と労働を要する代わりに現金化が早く、①はストックが積み上がる。**④で現金を作りながら①を仕込む**という組み方も成立します。
