# 副業ビジネス提案 一覧

調査・分析：Claude Code

## 前提条件（全提案に共通）

1. AI活用（自動化でき、従業員不在で運営できる）
2. 年商1億円以上が望めるマーケット
3. 成功事例に基づき、3か月以内に軌道に乗りやすい
4. 初期投資を抑えられる
5. この数年で伸びており、今後も期待できるジャンル

## 提案③：経験者マイクロ相談マーケット — **CtoC**

📁 [`proposal-03-experience-marketplace/`](./proposal-03-experience-marketplace/)

「AIが答えられないこと」だけを売るCtoC。特定のライフイベントを通過した個人が、これから通る個人に15〜60分だけ経験を売る場をつくり、マッチング・事前質問生成・事後要約をAIが全自動で回す。AIが一般知識を無料化した結果、**個人の生々しい一次情報の相対価値が上がっている**という構造変化が追い風。

| | |
|---|---|
| 顧客 | 一般個人 ↔ 一般個人（運営は手数料のみ） |
| 単価 | 3,000〜11,000円／件（手数料25%） |
| 初期投資 | 3か月累計 29万1,000円 |
| 3か月時点 | 月商 5〜10万円 |
| 市場 | シェアリングエコノミー 2.4兆円 → 2030年度 14.2兆円（CAGR 19.6%） |
| 難易度 | **3案で最も高い**（鶏と卵・資格法） |

## 3案の比較

| | **提案①** BtoB | **提案②** BtoC | **提案③** CtoC |
|---|---|---|---|
| 事業 | AI検索可視化 | 訪日AI旅程 | 経験者マイクロ相談 |
| 初売上まで | **4〜6週間** | 7〜8週間 | 8〜10週間 |
| 3か月時点の月商 | **50〜100万円** | 12〜20万円 | 5〜10万円 |
| 年商1億到達 | **18か月** | 2〜3年 | 3〜4年 |
| 収益の性質 | ストック | フロー | **プラットフォーム（非線形）** |
| 自分の労働との連動 | 商談分だけ連動 | 集客分だけ連動 | **噛み合えば完全に切れる** |
| 従業員不在 | ○（商談は残る） | **◎（完全無人）** | △（トラブル対応が残る） |
| 初期投資 | 23.4万円 | 26.9万円 | 29.1万円 |
| 最大リスク | AI事業者の規約／競合40社超 | 旅行業法／ハルシネーション | 鶏と卵／資格法 |
| 難易度 | **低** | 中 | 高 |

### 選び方

- **確実性と速度を取るなら 提案①。** 3案で唯一、3か月要件を余裕を持って満たす。
- **人と一切話さず完結させたいなら 提案②。** ただし確認作業（旅行業法の照会）に時間を要する。
- **時間はかかっても、労働から切り離された資産を作りたいなら 提案③。** 失敗確率も最も高い。

**現実的な組み方は、①でキャッシュを作りながら②か③を仕込むこと。** ②③はいずれも立ち上がりが遅いため、生活費を別の収入で支えられる状態でこそ挑戦できます。提案①で身につけるAI検索最適化の技術は、②③どちらの集客にもそのまま転用できます。
