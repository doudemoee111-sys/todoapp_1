# 提案④：越境EC輸出（個人・物販）── 壁打ち用の検証レポート

作成日：2026-08-23 / 調査・分析：Claude Code
[← 提案一覧に戻る](../README.md)

> 本レポートは「年商6,000万円・利益率20%以上が可能か」というご質問への検証が主目的です。提案①〜③とは性質が異なり、**在庫と物理作業を伴う物販**であることを先にお断りします。

## 0. 結論（先に答え）

| ご質問 | 答え |
|---|---|
| **年商6,000万円は可能か** | **可能。** 平均単価3万円 × 年2,000件 ＝ 1日5.5件の出荷。個人が回せる規模 |
| **利益率20%以上は可能か** | **条件付きで可能。** ただし①消費税還付を取る ②米国一本足を避ける ③仕入倍率2.3倍以上を維持する、の3つが揃って初めて届く |
| **半自動化できるか** | **できる。** リサーチ→出品→送り状発行まで既存ツールでほぼ繋がる。**ただし梱包と発送の物理作業だけは残る** |
| **どこに出店すべきか** | **eBayを主軸、Shopeeを併設。** 理由は§6。単一市場依存が今いちばん危険 |

**最大の変数は関税です。** この半年で米国の制度が3回変わりました（§4）。利益率20%の成否は、商品選定よりもここで決まります。

## 2. 何が売れているか（実データ）

### 2-1. 全体像

> **eBay中古品輸出では、中古・リファービッシュ品が売上の約6割を占め、単価が2.3倍という優位性がある。**

これが最も重要な事実です。**新品より中古のほうが売れていて、しかも単価が高い。** 理由は明確で、新品は世界中どこでも買えるが、**日本の中古品は日本にしかない**からです。状態が良く、丁寧に使われ、正規品である確率が高い ── この評判が日本セラーの資産になっています。

### 2-2. 売れているカテゴリ

| 区分 | カテゴリ | 補足 |
|---|---|---|
| **定番・大きく狙う** | アニメ・漫画・ゲーム関連 | フィギュア（限定版・絶版品は高額化）、eBay輸出の最強ジャンル |
| | 家電・電子機器 | カメラ、レンズ、ゲーム機、オーディオ |
| | ブランド品 | バッグ、時計、スニーカー |
| | コレクター向け | トレーディングカード、アンティーク |
| | ヴィンテージ | 衣類、家具、雑貨 |
| **価格帯** | $300〜$3,000の新品で、上位4カテゴリが月間1,000点超 | 日本人セラーの主戦場（2026年2月調査） |

2026年に販売実績が高かった具体例として、アニメグッズ詰め合わせ、限定版アクリルスタンド、呪術廻戦グッズまとめ売りなどが挙がっています。また**ビニールレコード**は中古が基本で、日本の歌手（和モノ・シティポップ）は海外で人気が高い商品として名指しされています。

### 2-3. ニッチで競争率が低いと考えられるカテゴリ

> ⚠️ **ここは仮説です。** 売れ筋データと「日本に供給が偏っている」構造から導いた推論であり、一次データで検証したものではありません。**W1–2で必ずTerapeak（eBay公式リサーチ）の実データで裏を取ってください。**

競争率が低くなる条件は3つあります。①**日本にしか良質な出物がない** ②**型番同定に専門知識が要り、素人セラーが手を出せない** ③**英語での商品説明が難しく、日本人セラーの参入が限られる**。この3つを満たす候補：

| 候補カテゴリ | なぜ競争率が低いか | 懸念 |
|---|---|---|
| **ビニールレコード（和モノ・シティポップ・City Pop）** | 海外で継続的な人気。盤の状態評価（Goldmine grading）に知識が要る。日本国内に膨大な出物 | 状態記載でクレームが出やすい。梱包に技術が要る |
| **オールドレンズ・フィルムカメラ** | 日本製の供給が圧倒的。カビ・クモリ・ヘリコイドの状態判定に知識が要る | 記載漏れによる返品リスク。DDP関税の影響を受けやすい価格帯 |
| **釣具（リール・ルアー）** | シマノ・ダイワの日本国内モデルは海外で高評価。型番体系が複雑 | 季節性がある |
| **楽器・エフェクター** | 日本製ブティックペダル、国産ヴィンテージギター。海外に固定ファン | 大型は送料が重い |
| **鉄道模型・絶版プラモデル** | 日本の絶版キットは海外で高騰。箱の状態が価値を決める | 箱の破損リスク、嵩張る |
| **万年筆・文具** | 日本製（パイロット・セーラー・プラチナ）の限定軸に海外需要 | 単価がやや低め |
| **茶道具・和食器・工芸品** | Etsy向き。真贋と作家の同定に知識が要る | 割れ物。梱包コスト高 |
| **自転車パーツ（ヴィンテージのシマノ等）** | コレクター需要が根強い | 市場が小さい |

**選定の考え方**：単価が高く（$150以上）、軽く（1kg以下）、壊れにくく、型番同定に知識が要るもの。この4条件を満たすほど、利益率と競争環境の両方が良くなります。上表なら**レコード・オールドレンズ・釣具・万年筆**が該当します。

## 3. 収益シミュレーション ── 年商6,000万円・利益率20%は届くか

### 3-1. 前提

```
平均販売単価 …… $200（≒30,000円 / 150円per$）
年商6,000万円 ⇒ 年間 2,000件 ⇒ 月167件 ⇒ 1日 約5.5件
```

**1日5.5件の出荷は、個人で回せる範囲です。** 1件15分（梱包＋ラベル）でも1.4時間/日。ここは問題になりません。

### 3-2. 1件あたりの損益（米国向け・DDP）

| 項目 | 金額 | 備考 |
|---|---|---|
| 売上 | **30,000円** | $200 |
| eBay手数料 | −5,400円 | 合計18%（FVF 13.25〜15.3%＋$0.30〜0.40/注文＋国際取引1.35%＋Payoneer為替2%） |
| **米国関税（DDP・セラー負担）** | **−3,750円** | 12.5%（§4） |
| 国際送料 | −3,000円 | 1kg想定。**実際は重量区切りと容積重量で変わる（下の注記）** |
| 梱包資材 | −200円 | |
| 仕入原価（税込） | −X | |
| **消費税還付** | **+X × 9.09%** | 輸出免税による還付（§5） |
| **営業利益** | **17,650 − 0.909X** | |

**利益率20%（＝6,000円）を出すために許される仕入額：**

```
17,650 − 0.909X = 6,000
X = 12,816円  ⇒  売価は仕入の 2.34倍 が必要
```

> **送料3,000円という置き方について（後日追記）**
>
> この試算は送料を市場ごとの固定値で置いていますが、実務ではここが最大の誤差源になります。
> 理由は2つ。
>
> 1. **料金は重量区切りで階段状に上がる。** 950gと1,050gでは1段違う。梱包後に100g超えて
>    1段上がると、その差はそのまま利益から消えます。
> 2. **嵩張るものは「容積重量」で課金される。** 容積重量(g) = 縦×横×高さ(cm) ÷ 除数 × 1000。
>    除数は手段ごとに違い（クーリエ5,000／国際小包6,000）、**EMSは容積重量を採りません（実重量のみ）**。
>    このため軽くて嵩張る荷物では、EMSがクーリエを逆転して最安になることがあります。
>
> たとえば実重量900gでも外箱込み30×25×20cmなら、国際小包の課金重量は2,500g。
> 実重量だけを見て仕入れると、送料で利益が消えます。
> 本試算の2.34倍は「1kg・嵩張らない荷物」の前提値として読んでください。
> 実際の判断は、重量と寸法から課金重量を出して行う必要があります
> （[blueocean ツール](../../../tools/blueocean/) の `shipping.py` / 送料タブで計算できます）。

### 3-3. 市場を変えると必要倍率がどう変わるか

| 販売先 | 手数料 | 関税 | 送料 | 必要な仕入倍率 |
|---|---|---|---|---|
| **米国（eBay・DDP）** | 18% | **12.5%** | 3,000円 | **2.34倍** |
| 欧州・豪州（eBay） | 18% | 現地VATはバイヤー負担が基本 | 3,000円 | **1.77倍** |
| 東南アジア・台湾（Shopee） | 3〜10% | 現地制度による | 2,000円（SLS） | **1.41倍** |

**この表が本レポートで最も重要です。** 米国のDDP関税12.5%が、必要な仕入倍率を**1.77倍から2.34倍へ、実に32%も押し上げています**。同じ商品でも、売り先を変えるだけで難易度が一段変わる。

### 3-4. 結論

**年商6,000万円・利益率20%は「可能だが条件付き」。** 必要な条件は5つ：

1. **課税事業者になって消費税還付を取る** ── これがないと利益率20%はほぼ不可能（§5）
2. **米国一本足を避ける** ── 欧州・豪州・東南アジアを併走させる
3. **仕入倍率2.3倍以上を安定して取れるカテゴリに絞る** ── ニッチ特化の理由はここ
4. **運転資金 200〜250万円を用意する** ── §7
5. **1日5〜6件の出荷を回す半自動化** ── §8

## 4. ★ 最大のリスク：関税制度がこの半年で3回変わった

**利益率20%の成否は、商品選定よりもここで決まります。** 時系列を整理します。

| 時期 | 何が起きたか | 影響 |
|---|---|---|
| 2025年8月 | **米国のde minimis（800ドル免税）廃止** | 少額商品も課税対象に |
| 2025年8月26日〜 | SpeedPAK EconomyがDDPに変更 | 関税がセラー請求に |
| **2025年10月17日〜** | **米国向け $2,500以下はDDP発送が必須** | **関税はセラー負担が原則に** |
| 2026年2月20日 | **米連邦最高裁が相互関税の大統領令を違法・無効と判決** | 制度が宙に浮く |
| 2026年5月7日 | 通商法122条による一律10%の暫定関税が発動 | 150日上限 |
| **2026年7月24日** | 122条が失効。**同日、通商法301条に基づく追加関税を60カ国・地域へ発動** | |
| **2025年8月27日** | **デミニミス撤廃を受け、日本郵便が米国宛ての引受を一部停止**（販売品の小形包装物・国際小包・EMS(物品)、$100超の個人間贈答） | **郵便が使えなくなった。書状・はがき・印刷物・EMS(書類)・$100以下の贈答は継続** |
| **2026年4月14日〜** | **米国税関が認証した事業者のアプリで関税を事前納付すれば、指定郵便局で米国宛て全郵便物の引受を再開** | 事前納付の手当てが要件 |
| **現在（2026年8月）** | **日本はMFN税率と合算して12.5%**（上乗せではなく合算方式） | 自動車・鉄鋼は対象外。重要鉱物・エネルギー・農産品・医薬品・特定電子機器も適用対象外 |

> セラー側の実感として、「売上は変わらないのに利益だけが落ちる」現象が起きています。**見えないコストとして関税が効いているのに、理由に気づいていないセラーが多い**と指摘されています。

### 何をすべきか

- **DDPを前提に価格を組む。** 関税12.5%を最初から原価に入れて出品価格を決める
- **HSコードごとの税率を確認する。** 「特定の電子機器」など適用除外の品目がある。**カテゴリ選定の段階で除外品目かどうかを調べると、それだけで利益率が数ポイント変わる**
- **売り先を分散する。** 米国比率を50%以下に保つ
- **制度変更を月次で確認する。** ジェトロ「米国関税措置への対応」と経産省「米国関税対策ワンストップポータル」を定点観測する
- **★ 米国宛ての配送手段を郵便前提で組まない。** 2025年8月に日本郵便が米国宛ての物品引受を
  一部停止しました。2026年4月14日から、米国税関が認証した事業者のアプリで関税を事前納付すれば
  指定郵便局で引受が再開しています。**その事前納付の手当てが済むまで、米国宛ては
  UGX（ゆうグローバルエクスプレス）／FedEx／DHL で見積もってください。**
  本レポートの送料前提（3,000円）は郵便を想定した値なので、クーリエに切り替えると
  上振れします。米国比率が高い計画ほど、ここが効きます。

## 5. 利益率を決めるもう一つの要素：消費税還付

**これを取るか取らないかで、利益率が約3ポイント変わります。**

輸出売上は消費税が免税（0%）です。一方、国内での仕入れでは消費税10%を払っています。この差額が**還付**されます。1件あたり仕入12,816円なら、還付は約1,165円 ── **利益6,000円のうち約2割が還付分**という計算です。

### 手続き上の必須事項

| 項目 | 内容 |
|---|---|
| **課税事業者であること** | **免税事業者は還付を受けられません** |
| 開業直後の場合 | 前々年度の売上がないため、そのままでは条件を満たさない。**「消費税課税事業者選択届出書」を税務署に提出**することで還付対象になる |
| 簡易課税を選んでいる場合 | 「消費税簡易課税制度選択不適用届出書」を出して**原則課税に切り替える**必要がある |
| 証憑の保存 | 輸出許可通知書・インボイス・発送記録など。**還付が認められないトラブルが実際に起きているため、税理士に確認のうえ運用を固めること** |

**届出には期限があります。** 事業開始年度中に出す必要があるため、**開業手続きと同時に着手してください**。ここを逃すと初年度の還付を丸ごと失います。

## 6. どこに出店すべきか

### 6-1. 主要プラットフォームの比較

| | **eBay** | **Shopee** | **Etsy** | Amazon Global |
|---|---|---|---|---|
| 得意な商材 | **中古・コレクター品・ホビー** | 日用品・小物・美容 | **ハンドメイド・工芸・ヴィンテージ** | 新品・型番商品 |
| 主要市場 | 米・欧・豪 | **東南アジア・台湾** | 米・欧 | 米・欧 |
| 手数料 | 合計17〜20% | **3〜10%**（SLS+利用時 +1.75%） | 出品＋取引＋決済 | カテゴリ別 8〜15%＋FBA |
| 集客力 | 大 | 大（当該地域で） | 月間約4.5億訪問 | 最大 |
| 競合 | **参入企業が比較的少ない** | 中 | 中 | **激烈**（価格競争） |
| 物流 | eBay配送プログラム／日本郵便／FedEx等 | **SLSで日本集荷→現地配送を一括** | 自己手配 | FBA（在庫を現地に置く） |
| 米国関税の影響 | **直撃** | 受けにくい | 直撃 | 直撃 |

### 6-2. 推奨：eBayを主軸、Shopeeを併設

**第1：eBay（主軸・売上の60〜70%）**

理由は3つ。
1. **中古・コレクター品の需要がここに集中している。** §2で見たとおり、日本セラーの強みは中古品。それが最も高く売れる場所がeBay
2. **参入企業が比較的少ない。** 英語でのやりとりが基本のため、日本人セラーの参入が限られている ── これは裏を返せば**言語がそのまま参入障壁になっている**ということ
3. **$300〜$3,000という単価帯が主戦場。** 1日5.5件で年商6,000万円という設計に、単価が合っている

**第2：Shopee（サブ・売上の30〜40%）**

理由は3つ。
1. **手数料が3〜10%とeBayの半分以下。** 同じ商品でも必要な仕入倍率が2.34倍→1.41倍に下がる
2. **米国関税の影響を受けない。** これが最大の理由。**単一市場依存が今いちばん危険**
3. **SLSで日本国内集荷から現地配送まで一括対応。** 物流の手間が少なく、副業の運用に向く

**第3：Etsy（ニッチ・任意）**
茶道具・和食器・工芸品・ヴィンテージ衣類をやるなら追加する。月間約4.5億訪問があり、「日本の手仕事」という文脈が最も高く評価される場所。ただし**主軸にはしない**。

### 6-3. なぜ「国内モールと同じ発想」では選べないのか

国内のAmazon・楽天・Yahoo!は**同じ日本の消費者を取り合う**ため、基本的に「どこに出すか」は集客力と手数料の比較で決まります。

海外は違います。**プラットフォームごとに顧客が住んでいる国が違い、したがって適用される関税・VAT・物流コストが丸ごと変わる**。つまり海外での出店先選びは、販路選びであると同時に**リスク分散の設計**です。米国の制度が半年で3回変わった今、ここを一本足にするのは事業設計として弱い ── これが「eBay＋Shopee」を推す最大の理由です。

| **合計（運転資金を除く）** | **約24万円** | |
| **合計（運転資金を含む）** | **約224〜274万円** | |

**提案①〜③が23〜29万円だったのに対し、本案は運転資金だけで200万円超が必要です。** 物販である以上これは避けられません。在庫回転を月2回にできれば運転資金は約107万円まで下がりますが、初期は回転が読めないため保守的に見るべきです。

**「初期投資を抑える」という当初条件に対しては、本案は明確に×です。** ここは正直にお伝えします。

## 8. 半自動化はどこまでできるか

### 8-1. 結論：リサーチ→出品→送り状発行までは繋がる。梱包と発送だけが残る

| 工程 | 自動化 | 使えるもの |
|---|---|---|
| **リサーチ** | ○ | **Terapeak**（eBay公式・落札実績の分析）、Sellerhacks（キーワード分析・20商品を1分で一括出品） |
| **仕入判断** | △→◎ | 相場データとの突合は自動化可。**AIで「仕入れるべきか」のスコアリングを自作すると差がつく**（§8-2） |
| **出品** | ◎ | **SAATS Commerce**（Amazon・メルカリ・ヤフオクから**最短30秒でeBay出品**）、**eBay Mag**（無料・複数マーケット一括・自動翻訳・通貨換算・在庫同期）、Tooliz |
| **翻訳** | ◎ | eBay Magの自動翻訳＋LLMで商品説明を生成 |
| **在庫管理** | ◎ | e-Stocker（在庫切れによるセラー都合キャンセルを防止） |
| **価格改定** | ◎ | 各ツールの自動改定機能 |
| **受注管理** | ◎ | SAATS Commerce |
| **★ 送り状・ラベル印刷** | **◎** | **SAATS Commerceが日本郵便・FedEx・DHLの送り状を発行し、送料比較まで対応** |
| **梱包** | **×** | **人間の手が必要。ここは消せない** |
| **発送（持込・集荷）** | △ | 集荷依頼で軽減できるが、荷造りは残る |
| **顧客対応** | ○ | 英語問い合わせの返信ドラフトをLLMで自動生成し、人が確認して送る |

**ご質問の「ラベル印刷まで半自動化できるか」への答えは Yes です。** SAATS Commerceのようなオールインワンツールが、受注から送り状発行・送料比較までを繋いでいます。感熱ラベルプリンターを1台買えば、印刷は完全に自動化できます。

### 8-2. AIで上乗せできること（既存ツールにない差別化）

既存ツールは「作業の自動化」までで、**判断の自動化**はしていません。ここが自作の余地です。

1. **商品写真 → 型番同定・状態記述・英語タイトル/説明の自動生成**（Vision対応LLM）。レコードの盤面グレーディングやレンズのカビ・クモリ判定の下書きまで作れる
2. **仕入判断のスコアリング** ── 落札相場・手数料・関税・送料・重量を入れて「この価格で仕入れて利益率20%を確保できるか」を自動判定。**§3の計算式をそのまま自動化する**
3. **英語問い合わせ・クレームの一次返信ドラフト生成**
4. **HSコード判定の補助** ── 関税率の適用除外品目かどうかを事前に判定（最終確認は必ず人・専門家）

**この4つを自作すれば、1日5.5件は無理なく回ります。** 逆に言えば、判断部分を自動化しないと件数が増えたときに自分がボトルネックになります。

## 9. リスクと法的な必須事項

| # | 項目 | 深刻度 | 内容と対策 |
|---|---|---|---|
| **1** | **古物商許可** | **必須** | **中古品の国内仕入れが発生する時点で対象。無許可営業は3年以下の拘禁刑または100万円以下の罰金。** 都道府県公安委員会に申請（手数料19,000円、審査に40日程度）。**着手前に必ず取得する** |
| **2** | **関税制度の流動性** | **最重要** | §4。半年で3回変わった。DDP前提で価格設計し、市場を分散し、月次で制度を確認する |
| **3** | **消費税還付の手続き** | **高** | §5。課税事業者選択届出書を**開業年度中に提出**。還付が認められないトラブルが実在するため、税理士に運用を確認 |
| 4 | 在庫リスク・資金繰り | 高 | 売れ残りは現金の死蔵。**回転しない商品は損切りルールを先に決める**（例：90日で30%値下げ、180日で処分） |
| 5 | 輸出規制品 | 高 | ワシントン条約（象牙・べっ甲・一部の革）、食品、化粧品、医薬品、**リチウム電池を含む機器**（航空輸送規制）、刀剣類。**カテゴリ選定の段階で除外する** |
| 6 | 真贋・知的財産 | 高 | ブランド品の偽物、二次創作グッズはアカウント停止リスク。**「限定版アクリルスタンド」等のIP商品は、正規品であることの証明を残す** |
| 7 | 為替 | 中 | 円安は追い風だが、反転すれば利益が消える。**円高120円/$を想定した損益も作っておく** |
| 8 | アカウント停止 | 中 | eBayのポリシー違反、無在庫販売の規約、評価低下。**リミットの範囲内で堅実に運用する** |
| 9 | **物理作業が残る** | 中 | 梱包・発送は自動化できない。**「従業員不在」という当初条件には応えられない** |

## 10. 当初5条件との照合（正直な採点）

| 当初条件 | 判定 | 理由 |
|---|---|---|
| AI活用・自動化 | ○ | リサーチ〜ラベル発行まで自動化可。判断のAI化で差別化できる |
| **従業員不在** | **×** | **梱包・発送の物理作業が残る。** 件数が増えれば外注が必要になる |
| 年商1億以上のマーケット | ◎ | 越境EC市場 1.01兆ドル、CAGR 23.1% |
| 3か月で軌道 | ○ | **既存プラットフォームなので集客が不要。** 仕入れて出せば売れる。3案の中では最も速く初売上が立つ可能性がある |
| **初期投資が低い** | **×** | **運転資金200万円超が必須** |
| 伸びており今後も期待 | ◎ | CAGR 23.1%。ただし関税と為替の変動は大きい |

**前3案とは明確に性格が違います。** 提案①〜③が「在庫も物流も持たない、労働から切り離す」設計だったのに対し、本案は**在庫を持ち、体を動かす**ビジネスです。そのぶん、**需要を新しく作る必要がなく、初売上が最も早い**という強みがあります。

## 11. 検証のための最初の30日

いきなり200万円を投じるのは危険です。**10万円で仮説を検証してから判断してください。**

| 週 | やること | 判定基準 |
|---|---|---|
| **W1** | 古物商許可を申請する（審査40日のため最初に着手）。並行して税理士に消費税還付の相談 | 申請完了 |
| **W1–2** | **Terapeakで候補カテゴリの実データを取る。** §2-3の仮説8つについて、直近90日の落札実績・平均単価・出品数（＝競合数）を調べ、**「売れている数 ÷ 出品数」でカテゴリを順位づける** | 上位3カテゴリを確定 |
| **W3** | **その3カテゴリで、国内の仕入価格と海外の落札価格を30件突合する。** §3の計算式に入れて、**仕入倍率2.3倍を超える商品が何割あるか**を数える | **3割を超えれば継続、下回れば別カテゴリへ** |
| **W4** | 手元の不要品10点を実際にeBayに出品して売ってみる（仕入ゼロ）。**梱包・発送・関税・返品の実務を体で覚える** | 10件完了 |

**W3の判定が本命です。** ここで「仕入倍率2.3倍を超える商品が3割未満」なら、そのカテゴリでは利益率20%は達成できません。**カテゴリを変えるか、売り先をShopee・欧州にずらすか**の判断をこの時点で行ってください。

この4週間の実支出は、古物商許可19,000円＋ツール試用＋梱包資材で**10万円以内**に収まります。
