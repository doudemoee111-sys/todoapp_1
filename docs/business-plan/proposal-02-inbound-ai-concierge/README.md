## 0. 結論（3行）

**訪日外国人向けに「実際に行ける・予約できる日本旅行プラン」をAIが自動生成して直接販売する、完全デジタルのD2Cサービス。**

この市場では既に **1件$120〜$400の人力コンシェルジュ** が成立している。そこをAIで無人化し、**$39** で提供して価格ごと市場を取りに行く。

初期投資 **約27万円**、損益分岐 **月18件**、需要検証済みのため3か月以内の初回売上が現実的。

## 2. なぜ「インバウンド×BtoC」なのか（候補5領域の比較）

BtoCで条件に合いそうな領域を、**市場規模と成長率の実データ**で並べた。

| 領域 | 市場規模 | 成長率 | 無人化 | 3か月 | 判定 |
|---|---|---|---|---|---|
| **インバウンド** | **9兆4,549億円** | **+16.4%／13年で8.6倍** | ○ | ○ | **◎ 採用** |
| 推し活 | 3.8〜4.1兆円 | 拡大中（人口2,000万人） | △ | ◎ | △ 著作権リスク |
| ペット関連 | 1兆9,108億円 | +2〜6% | ◎ | ○ | ○ 成長が穏やか |
| 占い・スピリチュアル | 997億円（占い単体） | CAGR 7.4% | ◎ | ◎ | △ AI占いが既に飽和 |
| マッチングアプリ周辺 | 1,094億円 | +7% | ◎ | ◎ | △ 写真代行が7社超で競合過多 |

**成長率が一桁違う。** インバウンドは他候補が数%成長のなかで**+16.4%**、しかも国策として2030年まで伸ばすことが決まっている。「この数年で伸びてきていて今後も望めそう」という条件に、データ上もっとも忠実に答える領域がここだった。

### 除外した領域の理由

- **推し活**：市場は4兆円と巨大だが、収益化の中心が二次創作グッズになりやすく、**著作権侵害のリスクが事業の根幹に居座る**。個人の副業で背負う種類のリスクではない。
- **ペット**：無人化との相性は最良だが、市場成長が年2〜6%。「この数年で伸びてきている」の条件には弱い。
- **占い・AI診断**：条件適合は高いが、**生成AIで低コスト・大量生産できるがゆえに既に供給過多**。同じ理由で参入も容易＝差別化が続かない。
- **マッチングアプリ写真**：市場+7%、かつ撮影代行が既に7社以上、AI写真生成サービスも複数。単価7,700円〜1万円で価格競争済み。

## 3. インバウンド市場で「どこを取るか」

### 3-1. 市場データ

| 指標 | 数値 | 出典 |
|---|---|---|
| 訪日外国人旅行消費額（2025年） | **9兆4,549億円**（前年比 +16.4%） | 観光庁 |
| 訪日外国人客数（2025年） | **約4,268万人**（過去最高） | 観光庁 |
| 13年間の伸び | 1.1兆円（2012年）→ 9.45兆円 ＝ **8.6倍** | 観光庁 |
| 消費の内訳 | 宿泊費・飲食費・交通費で **全体の約7割** | 観光庁 |
| 欧米豪の1人あたり支出 | **40万円超** | 観光庁／やまとごころ |
| 政府目標（2030年） | **6,000万人・15兆円**（2026年3月27日 閣議決定・据え置き） | 観光立国推進基本計画（第5次） |

消費は「買い物」から**「滞在・体験」へ明確にシフト**した。つまり旅行者が金を払う対象が、モノから**「どこで何を食べ、何を体験するか」という意思決定そのもの**に移っている。

### 3-2. 旅行者側の痛み（実データ）

> 旅館やミシュランガイド掲載レストランは**電話予約のみ**の対応がほとんどで、訪日外国人にとって言語の壁となっている。
> 日本のレストランの多くはオンライン予約に対応しておらず、英語UIも持たないため、**外国人旅行者には高価で非現実的な選択肢しか残らない**。

FIT（個人手配旅行）化が進むほど、この壁に直接ぶつかる人が増える。**日本語が読めないことが、そのまま「行けない・食べられない」に直結している。**

### 3-3. ★ 決定的な発見：この痛みは、既に人力で商売になっている

| 既存サービス | 形態 | 価格 |
|---|---|---|
| 日本旅行の専門家によるカスタム旅程 | 人力 | **$400〜**（1〜2週間の旅程レビュー） |
| 電話・WhatsApp・メール無制限の旅程調整 | 人力 | **¥18,000／家族**（4日以上の旅行） |
| Tabiko（チャット型コンシェルジュ） | **実在のコンシェルジュ**が対応 | アプリ課金（30万DL超・4.9★） |
| TableAll／Jasumo | **人が代理で予約** | 予約代行手数料 |
| AI旅程サービス（既出の1社） | AI | ¥500（≒$3） |

**この価格表がそのまま事業機会である。**
上の帯（$120〜$400）は人件費で成立しているので値下げできない。下の帯（¥500）はAIだが、後述のとおり品質が実用に届いていない。

**その中間の $39 に、AIで品質を担保した商品を置く。** これが本案の勝ち筋。

### 3-4. 市場規模の試算（TAM）

```
訪日外国人 4,268万人／年
  × FIT（個人手配）比率 …… 保守的に 60%     = 2,561万人
  × 旅程作成に金を払う層 …… 保守的に 0.5%    =  12.8万人
  × 単価 $39（≒5,900円）                    ≒  7.5億円／年
```

**保守的な仮定でもTAM 7.5億円。** 転換率を1%と置けば15億円、単価を予約代行込み$60にすれば23億円。年商1億円は**シェア13%で到達**する計算になる。政府目標どおり2030年に6,000万人まで伸びれば、この分母がさらに1.4倍になる。

## 4. 事業設計

### 4-1. 何を売るか

**商品名（仮）：Japan Trip Kit** — 「読む情報」ではなく「**実行できる旅程**」を売る。

```
【無料】AI旅程ジェネレーター（3日ぶんまで）
   └ リード獲得と実力の証明。ここで品質を見せる
        ↓
【本命】Trip Kit ……………………………… $39（約5,900円）
   ├ 実在検証済みの日別プラン（営業時間・定休日・休業を機械照合）
   ├ 日本語の一次情報から抽出した「現地の注意点」
   │   （要予約／現金のみ／写真禁止／持ち込み不可／整理券制など）
   ├ 予約導線（英語予約可＝直リンク／日本語のみ＝記入例つき）
   ├ 店で見せる日本語カード（アレルギー・ハラル・ベジタリアン・要望）
   └ オフラインで開けるPWA（機内・地下鉄でも見られる）
        ↓
【追加】予約リクエスト代行 ……………… $9／件
   └ 飲食店・体験施設のみ。宿泊・交通は扱わない（§9-1 法規制）
        ↓
【追加】旅行中サポート ………………… $19／週
   └ 現地での質問にAIが即答。定休日・運休の差し替えも自動
```

### 4-2. 無料AIに対する差別化 ── ここが事業の心臓

「ChatGPTに聞けば無料では？」への回答が、そのまま商品の存在理由になる。

| 論点 | 無料の汎用AI | Trip Kit |
|---|---|---|
| **店が実在するか** | **確認しない**（閉店した店・存在しない店を平然と出す） | Google Places APIで**実在・営業時間・定休日を機械照合**。落ちた候補は自動で差し替え |
| 情報源 | 英語の二次情報が中心 | **日本語の一次情報**（公式サイト・日本語レビュー）を読ませる |
| 現地の作法 | 出てこない | 「現金のみ」「要予約」「撮影禁止」など**日本語にしか書かれていない条件**を抽出 |
| 予約 | できない | 予約導線を用意。日本語のみの店は記入例を同梱／代行も可 |
| 携行性 | チャット履歴を遡る | オフラインPWA。**電波がなくても開く** |

**旅行者にとって最大の恐怖は「行ったら閉まっていた」。** 汎用AIのハルシネーションが実害に直結する領域なので、**「検証済みであること」自体が課金理由になる。**

### 4-3. ユニットエコノミクス（1件 $39 ＝ 約5,900円）

| 項目 | 金額 |

| LLM API（生成＋日本語読解＋多言語化） | 約120円 |

固定費は月**約2.2万円**（§8）。→ **月4件で固定費を回収、月18件で生活費水準の利益**、月100件で月粗利約54万円。

## 5. 「従業員不在」を成立させる構造

```
┌─ L1 受注 ────────────────────────────────────┐
│ Webフォームで条件を受け取る（日程／人数／興味／  │
│ 食事制限／予算／移動の好み）→ Stripeで即時決済   │
└──────────────────────────────────────────────┘
                  ↓
┌─ L2 候補生成 ────────────────────────────────┐
│ LLMが条件から候補スポットを立案                │
│ 日本語の公式サイト・レビューを読ませて条件抽出    │
└──────────────────────────────────────────────┘
                  ↓
┌─ L3 実在検証（品質の要）───────────────────────┐
│ Google Places APIで営業時間・定休日・存在を照合  │
│ 落ちた候補は自動で差し替え、再検証               │
│ ※ここを通らないものは絶対に納品しない            │
└──────────────────────────────────────────────┘
                  ↓
┌─ L4 生成・納品 ──────────────────────────────┐
│ 日別プラン／日本語カード／予約導線／PWAを生成    │
│ メール自動送信（Resend）                       │
└──────────────────────────────────────────────┘
                  ↓
┌─ L5 集客 ────────────────────────────────────┐
│ 無料ジェネレーターをSNS・コミュニティに置く       │
│ 英語SEO＋GEO（＝提案①の技術をそのまま自社に使う）│
└──────────────────────────────────────────────┘
```

**人間の稼働**：例外対応（検証に落ち続けた旅程の目視）と、予約代行の例外のみ。**平常時の受注〜納品に人は一切介在しない。** 時差のある海外顧客を相手にしながら、こちらが寝ている間に売上が立つ構造になる。

**技術スタック**：Next.js＋Supabase＋Vercel／Claude API／Google Places API／Stripe／Resend

## 6. 集客 ── BtoCで最も難しい部分をどう解くか

BtoCの最大の敵は顧客獲得コスト（CAC）。**広告費をかけずに立ち上げる**設計にする。

| チャネル | 具体策 | なぜ効くか |
|---|---|---|
| **無料ジェネレーター** | 3日ぶんまで無料生成。品質を先に見せる | 商材が営業ツールを兼ねる（提案①と同じ構造） |
| **旅行コミュニティ** | Reddit の r/JapanTravel など。**まず質問に無償で答え続ける** | 日本旅行の相談が毎日大量に流れている。ただし**露骨な宣伝は即BAN**（§9-3） |
| **ショート動画** | 「AIが作った旅程の店が閉まっていた」検証系など | 動画の主役が日本の風景＝素材が強い |
| **Pinterest** | 旅程ビジュアルを投稿 | 旅行계画の検索媒体として英語圏で強い |
| **英語SEO＋GEO** | 「4日間の京都で子連れ・ベジタリアン」等のロングテール | **提案①で作るAI検索最適化の技術を、そのまま自社集客に転用できる** |

### ★ 提案①との相乗効果
提案①（AI検索可視化）で身につけるのは「**AIに引用される作り方**」そのもの。提案②はその技術の**最初の実験台**にできる。英語圏の旅行者がChatGPTに「best 5-day Japan itinerary for vegetarians」と聞いたとき、自社が挙がる状態を作る。**提案①のノウハウが提案②の集客費をゼロに近づけ、提案②の実績が提案①の営業事例になる。**

## 9. リスクと対策 ── 先に潰す4つ

| # | リスク | 深刻度 | 対策 |
|---|---|---|---|
| **1** | **旅行業法**：報酬を得て**宿泊・運送の手配**を行うと旅行業登録が必要になる | **最重要** | **宿泊・交通の予約は一切扱わない。** 飲食店・体験施設の予約リクエストのみに限定し、宿泊/交通は「自分で予約するための情報提供」にとどめる。**開業前に観光庁または行政書士へ照会し、書面で確認を取る**（費用は初期投資の予備費で対応） |

| **3** | **コミュニティ規約**：Redditなどで宣伝と見なされBANされる | 高 | **先に貢献、後に告知**を徹底。各subredditの self-promotion ルールを読み、無償回答の実績を作ってから、許可された形でのみ言及する |
| **4** | 無料AIとの competition | 中 | §4-2の差別化（実在検証・日本語一次情報・予約導線・オフライン）を商品説明の中心に置く。**「無料AIで作った旅程の危うさ」を実証するコンテンツ**自体が集客になる |
| 5 | 為替・インバウンド政策の変動 | 中 | 円安が終われば単価の割安感は薄れる。**日本人の国内旅行・海外旅行版へ横展開できる設計**にしておく |
| 6 | Google Places APIのコスト増 | 中 | 検証結果をキャッシュ（同一スポットは再利用）。原価の上限を1件500円に設定して監視 |
| 7 | 季節変動（訪日は桜・紅葉に集中） | 中 | 閑散期はコンテンツ制作とSEO/GEO資産の積み増しに充てる |
| 8 | 本業の就業規則・税務 | 要確認 | 副業可否を先に確認。**海外顧客への販売は消費税が不課税**になる場合があり、免税事業者の判定に影響するため税理士に確認 |

## 10. 提案①との比較 ── どちらを選ぶか

| | **提案①**（BtoB・AI検索可視化） | **提案②**（BtoC・訪日AI旅程） |
|---|---|---|
| 顧客 | 士業・クリニック（法人） | 訪日外国人（個人） |
| 単価 | 月5〜30万円（ストック） | $39（フロー） |
| 初売上まで | **4〜6週間** | 7〜8週間 |
| 3か月時点の月商 | **50〜100万円** | 12〜20万円 |
| 収益の性質 | **ストック（積み上がる）** | フロー（毎回集客が要る） |
| 営業 | **商談が必要**（人が出る） | **不要**（完全セルフサーブ） |
| 無人化の徹底度 | 商談だけ人が残る | **完全無人が可能** |
| 市場成長率 | AI市場 CAGR 36% | インバウンド +16.4% |
| 初期投資 | 23.4万円 | 26.9万円 |
| 最大リスク | AI事業者の規約・競合40社超 | **旅行業法・ハルシネーション実害** |

### 使い分けの結論

- **早く現金がほしい／人と話すのが苦でない** → **提案①**。ストック収益で積み上がるため、年商1億への距離も近い。
- **人と一切話さずに完結させたい／時間が本当に取れない** → **提案②**。商談ゼロ、時差の向こうで売上が立つ。ただしフロー収益なので、集客の手を止めると売上も止まる。

**併走も可能で、しかも相性が良い。** §6で述べたとおり、提案①で身につけるAI検索最適化の技術は、そのまま提案②の集客エンジンになる。提案②を**提案①の技術を試す自社案件**として位置づけると、学習と売上が同じ作業から生まれる。
