## 0. 結論（3行）

**「AIが答えられないこと」だけを売るCtoC。** 特定のライフイベントを通過した個人が、これから通る個人に15〜60分だけ経験を売る場をつくり、マッチング・事前準備・事後要約をAIが全自動で回す。

AIが一般知識を無料化した結果、**個人の生々しい一次情報の相対価値が上がっている**。この非対称が本案の追い風。

ただし先にお伝えすべきことがあります。**CtoCは、ご提示の5条件に対して3案の中で最も相性が悪い形態です**（§1）。それを承知のうえで、CtoCで唯一勝ち目がある構造を提示します。

## 1. 先に、正直な評価 ── CtoCは5条件に構造的に不利

提案①②と同じ熱量で「いけます」と書くことはできません。理由は3つあり、いずれもCtoCの構造そのものに由来します。

| 構造的な不利 | 内容 |
|---|---|
| **鶏と卵** | CtoCは両面市場。売り手がいないと買い手が来ず、買い手がいないと売り手が続かない。**「3か月で軌道」という条件に対して最も厳しい形態**。提案①が4〜6週間で初売上に届くのに対し、CtoCは片側を集める期間が先に必要になる |
| **トラブル対応** | 個人同士の取引には必ず揉め事が起きる（無断キャンセル、期待外れ、暴言）。**「従業員不在」を100%は満たせない**。設計で最小化はできるが、ゼロにはできない |
| **手数料モデルの分母** | 年商1億円＝手数料25%ならGMV4億円。**自分の売上ではなく他人の取引総額を4億円積む必要がある**。提案①なら月15万円×約56社で届く数字が、CtoCでは桁違いの取引件数を要求する |

**それでもCtoCを検討する価値があるのは、当たったときの伸び方が非線形だからです。** 供給と需要が噛み合った瞬間から、自分の労働時間と売上が完全に切り離れます。提案①②は「自分が動いた分だけ売れる」構造を最後まで引きずりますが、CtoCだけはそこから抜けられます。

**成長率で見ると、CtoCの中でシェアリングエコノミー（=スキル・経験・空間・移動のシェア）が突出しています。** CtoC-ECは+1.82%と既に成熟期に入っており、「この数年で伸びてきている」という条件には応えられません。

### 3-2. ★ 重要な発見：モノ系CtoCの道は既に塞がっている

調査の途中で、有力に見えた案がひとつ潰れました。記録として残します。

当初は「**AIが写真から値付け・出品文を自動生成する特化型フリマ**」を考えていました。実家じまい・遺品整理で出てくるモノの価値が分からず二束三文で処分されている、という痛みは実在し、リユース市場も14年連続で伸びています。

**しかし、この機能は既に大手が無料で提供済みでした。**

| サービス | 提供済みの機能 | 時期 |
|---|---|---|
| メルカリ | AI出品サポート（写真から最短3タップ・3〜5秒で出品情報を自動生成）／AI価格査定（0.1秒で最適価格） | 提供中 |
| Yahoo!フリマ | 「らくらくAI査定」— LINEに写真1枚送るだけで相場が分かり、出品下書きまで自動生成 | 2025年10月〜 |
| ブックオフ・セカンドストリート等 | AI査定システムを導入し、経験に頼っていた査定を標準化 | 提供中 |

**プラットフォーム自身が無料で配っている機能で、個人が課金することはできません。** モノ系CtoCは、この時点で選択肢から外れました。

## 4. なぜ「経験のCtoC」なのか ── AI時代の構造変化

### 4-1. AIが増やしたもの、減らしたもの

生成AIの普及で、**一般的な知識の価値はゼロに近づきました**。「中学受験の仕組み」も「注文住宅の流れ」も「介護保険の申請方法」も、ChatGPTが無料で完璧に答えます。

その裏返しとして、**相対的に価値が上がったもの**があります。

| AIが答えられること | AIが答えられないこと |
|---|---|
| 制度・手順・一般論 | **その人が実際に何を選び、何を後悔したか** |
| 平均値・統計 | **固有の状況での判断** |
| 建前・公式見解 | **利害関係のない本音** |
| 網羅的な選択肢 | **「私ならこうする」という一人の断言** |

**この非対称が、そのまま商材になります。** 提案①で見つけた「AIは一次情報を引用したがる」という洞察と、根は同じです。AIが薄めた世界で、濃い一次情報の希少価値が上がっている。

### 4-2. 需要が実在する証拠

| 事実 | 意味 |
|---|---|
| ビザスクに**80万人超**のエキスパートが登録、**年間12万件超**のマッチング | 「人の経験を短時間だけ買う」という行動様式が既に確立している（ただしBtoB） |
| ココナラが売上高・売上総利益・EBITDAともに**過去最高を更新** | CtoCのスキル売買市場は成長している |
| SNSに「#家づくり後悔」「#中学受験2026」等の当事者投稿が大量に存在 | **供給側（語りたい経験者）が既に無料で発信している** |

**ビザスクが確立したスポットコンサルという形式は、BtoBには存在するのにCtoCには存在しません。** 一般個人が一般個人の経験を、正規のルートで、安全に、有料で買う場所がない。だから今はSNSのDMで無償・無秩序にやりとりされています。

## 5. 事業設計

### 5-1. サービスの形

```
【相談したい人】                        【経験した人】
  悩みを書く                             プロフィール登録
      ↓                                       ↓
  AIが悩みを構造化し、                   AIが経験を構造化し、
  「誰に聞くべきか」を判定  ←マッチング→  検索可能な形に整える
      ↓
  AIが「15分で聞くべき質問リスト」を自動生成
      ↓
  オンラインで15〜60分 話す（ブラウザ完結）
      ↓
  AIが文字起こし・要約・やることリストを自動生成して両者に配信
      ↓
  決済はStripe Connectが自動で分配（運営は資金を預からない）
```

### 5-2. 価格と手数料

| プラン | 相談者の支払い | 経験者の受取 | 運営の手数料 |
|---|---|---|---|
| 15分 ライト | 3,000円 | 2,250円 | 750円（25%） |
| 30分 スタンダード | 6,000円 | 4,500円 | 1,500円（25%） |
| 60分 じっくり | 11,000円 | 8,250円 | 2,750円（25%） |
| テキスト相談（非同期） | 2,000円 | 1,500円 | 500円（25%） |

**手数料25%はココナラ（22%〜）とほぼ同水準。** AIによる事前質問生成と事後要約という付加価値があるため、この水準は説明できます。

### 5-3. 第1テーマの選び方 ── ここで事業の成否が決まる

**全ジャンルを一度に開くのは自殺行為です。** 1つのライフイベントに絞れば、供給側は**20〜30人で開始できます**。

選定基準：

| 基準 | 理由 |
|---|---|
| 当事者数が多い | 需要の母数 |
| 悩みが深く、金額の大きい意思決定に関わる | 数千円を払う理由になる |
| 情報が個別的でAIが答えられない | 本案の存在理由 |
| 人に相談しづらい／周囲に経験者がいない | 有料で他人に聞く動機 |
| **資格法に触れにくい** | 医師法・弁護士法・宅建業法を避ける（§11-1） |
| 経験者に「語りたい」動機がある | 供給が集まる |

**候補（W1–2で実際に検証して1つに決める）**

| 候補 | 強み | 懸念 |
|---|---|---|
| **住宅購入・注文住宅** | 数千万円の意思決定。営業トークではない本音の需要が明確。SNSに後悔談が溢れている＝供給側の動機が実証済み | 一生に一度でリピートなし。宅建業法・建築士法の線引きに注意 |
| 中学受験・高校受験 | 首都圏の受験率は高水準。親の悩みが深く、塾は高額。リピート性あり | 情報商材化しやすく、質の担保が難しい |
| 地方移住・二拠点生活 | 失敗コストが大きく、現地の実情はネットに出ない | 当事者数が上2つより少ない |
| 親の介護の入口 | 団塊世代の後期高齢者化で当事者が確実に増える | センシティブ。医療的助言の禁止を厳格に設計する必要 |

**第1候補は「住宅購入・注文住宅」。** 単価の大きい意思決定で、資格法の線引きが比較的引きやすく、何よりSNS上で経験者が既に大量に語っている＝**供給側を集める難易度が最も低い**からです。

## 6. 鶏と卵をどう解くか

CtoC最大の難所です。3手で解きます。

### 手1：需要側を先に「予約」で溜める（供給ゼロで始める）
サービス公開前に「〇〇の経験者に聞ける場を作ります。聞きたいことを書いてください」というフォームだけを公開する。**集まった相談内容そのものが、経験者を口説く材料になります**（「あなたの経験を待っている人が37人います」）。

### 手2：供給側は自分の手で20人集める
20人なら**自動化せず、SNSで一人ずつDMを送って口説けます**。ここは唯一、意図的に手作業でやる工程。提案①でW5–6に「手作業で全力納品」を置いたのと同じ考え方で、**自動化の前に、何が価値なのかを自分の手で確かめます**。

### 手3：最初の30件は手数料ゼロにする
経験者の受取を100%にして、実績と口コミを先に作る。**30件の実施記録が、次の100人の供給側を連れてきます。**

> CtoCの立ち上げは「まずは供給側を集めることに注力せよ」が定石です。本案では手1で需要の証拠を作ってから手2で供給を口説く、という順序にして、口説く難易度を下げています。

## 7. 無人化の構造と、残る人間の仕事

### 自動で回る部分（平常運転の100%）

| レイヤー | AIの仕事 |
|---|---|
| L1 受付 | 相談内容を自由記述で受け取り、**構造化**（何に困り、何を決めたいのか） |
| L2 マッチング | 経験者のプロフィールと相談内容を照合し、上位3人を提示 |
| L3 事前準備 | **15分を無駄にしないための質問リストを自動生成**。相談者に事前送付 |
| L4 実施 | ブラウザ完結のビデオ通話（外部サービスを埋め込み）。運営は介在しない |
| L5 事後 | 文字起こし → 要約 → **やることリスト**を自動生成し両者へ配信 |
| L6 決済 | Stripe Connectが自動分配。**運営は資金を預からない**（§11-2） |
| L7 供給側の登録 | 経験を書いてもらうだけでAIがプロフィールを整形。**登録の面倒さを消す** |

### 人間に残る仕事（これはゼロにできない）

- **トラブル対応**：無断キャンセル、期待外れ、不適切な発言
- **供給側の初期審査**：最初の20〜50人は目視で確認する

**最小化策**：①相談前に「これは専門家の助言ではなく個人の経験談です」を必ず同意させる ②評価が一定を下回った経験者を自動で非公開にする ③返金は自動ルール化（無断キャンセルは全額返金・自動）。それでも**月に数件は人が出る前提で設計します**。ここが「従業員不在」を△にした理由です。

## 10. 年商1億への距離 ── 正直な試算

```
手数料25% で 年商1億円 ⇒ GMV 4億円
平均単価 6,000円（30分プラン）とすると …… 年間 66,700件
                                          ＝ 月 5,560件
                                          ＝ 1日 185件
```

**1日185件のマッチングは、CtoCとしては相当な規模です。** ココナラ級とは言いませんが、単一テーマでは到底届きません。

到達には次のいずれかが必要です。

| 打ち手 | 効果 |
|---|---|
| **テーマを横展開する**（住宅 → 受験 → 移住 → 介護 …） | 1テーマ月500件×10テーマで月5,000件。**これが本線** |
| **単価を上げる**（60分11,000円の比率を上げる） | GMV4億に必要な件数が36,400件／年に減る |
| **法人プランを足す**（企業が福利厚生として社員に配る） | CtoCの純度は下がるが、GMVの積み上がりが速い |

**現実的な到達時期は3〜4年目**とみています。提案①（18か月）より明確に遠い。**「年商1億以上望めるマーケット」という条件は市場規模としては満たしますが、自社がそこに届く速度は3案で最も遅い**、というのが正直な評価です。

## 11. リスクと対策

| # | リスク | 深刻度 | 対策 |
|---|---|---|---|
| **1** | **資格法**：医師法・弁護士法・宅建業法。個人の経験談を超えて「助言」に踏み込むと無資格業務になりうる | **最重要** | 規約と画面上で「**これは専門家の助言ではなく、個人の経験の共有です**」を明示し、相談前に同意を取る。診断・治療・法律判断・不動産取引の媒介にあたる発言を禁止事項として列挙。**開業前に弁護士へ相談し、規約をレビューしてもらう**（初期投資8万円の使途） |

## 12. 3案の比較

| | **提案①** BtoB | **提案②** BtoC | **提案③** CtoC |
|---|---|---|---|
| 事業 | AI検索可視化 | 訪日AI旅程 | 経験者マイクロ相談 |
| 顧客 | 士業・クリニック | 訪日外国人 | 一般個人 ↔ 一般個人 |

| 収益の性質 | ストック | フロー | **プラットフォーム（非線形）** |

| 最大リスク | AI事業者の規約／競合40社超 | 旅行業法／ハルシネーション | **鶏と卵／資格法** |
| 難易度 | 低 | 中 | **高** |

### 選び方

- **確実性と速度を取るなら 提案①。** 3案で唯一、3か月要件を余裕を持って満たします。
- **人と話さず完結させたいなら 提案②。**
- **時間はかかっても、労働から完全に切り離された資産を作りたいなら 提案③。** ただし**難易度は3案で最も高く、失敗確率も最も高い**ことは明記しておきます。

**現実的な組み方をひとつ挙げるなら、①でキャッシュを作りながら③を仕込むことです。** ③は立ち上がりが遅いぶん、生活費を別の収入で支えられる状態でこそ挑戦できます。①→③の順は、リスクの取り方として理にかなっています。

## 13. 今週やる5つのこと

1. **本業の就業規則で副業可否を確認する**（3案共通の最初のゲート）
2. **第1テーマの候補4つについて、SNSで当事者の投稿を50件ずつ読む。** 「これは金を払ってでも人に聞きたい悩みか」を自分の目で判定する
3. **ココナラとビザスクに登録し、実際に1件買ってみる。** マッチングから実施、事後までの体験を通して、何が足りないかを掴む（費用1万円以内）
4. **弁護士に「個人の経験談の有料マッチング」の適法性を相談する。** 医師法・弁護士法・宅建業法の線引きと、規約に入れるべき禁止事項を確認する（時間がかかるので最初に着手）
5. **需要側の「予約フォーム」だけを作って公開する。** サービスは作らない。**まず「聞きたい人が本当にいるか」だけを測る**

**W3–4で需要側が50人集まらなければ、テーマを変えるか、提案①に切り替えてください。** ここが最も安いタイミングの撤退判断です。初期投資は規約整備の8万円を除けばまだ数万円しか使っていません。
