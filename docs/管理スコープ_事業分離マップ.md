# 管理スコープ・事業分離マップ（必読）

> このリポジトリ（todoapp_1）には**複数の独立事業**がブランチ単位で同居しています。
> 混ぜない・跨がないのが大原則。人にもエージェント（トリガー実行セッション含む）にも
> 必ず守ってほしい「どの事業がどこにあるか」の地図です。
>
> 現在の管理者: 雑学ジャンル管理者（＝この地図の維持責任者）。
> 睡眠チャンネルは**別部門**。FX/ゴールドは引き継ぎ先が未定のため、当面はこの管理者が
> **雑学とは分離した状態で**引き続き管理する。

## フォルダ分離（確認済み・混在なし）
- 雑学ブランチ = `pipeline/`（`fx/` は**存在しない**）。
- FXブランチ = `fx/`（`pipeline/` など動画系は**存在しない**）。
- → **同じコマンドが他事業を叩けない**。例: FXブランチで `python3 pipeline/run.py` は「無い」ので失敗。
  雑学ブランチで `node fx/scripts/build_pages.mjs` は「無い」ので失敗。構造上、跨げない。

## FX/ゴールドを混ぜないためのルール（当面この管理者が保持）
1. **FXは動画チャンネルに一切触れない**。YouTube 認証・アップロードは使わない
   （データ収集→`fx/data/`→ページ生成→`fx/web/`・公開 artifact→ Google Drive 反映のみ）。
2. **触ってよいのは `fx/` 配下だけ**。雑学の `pipeline/` や睡眠の資産に手を入れない。
3. **ブランチを跨がない**。FX作業は `claude/cloud-business-automation-4kqckb` 上でのみ。
   雑学作業は `claude/web-automation-setup-ifetgk` 上でのみ。相互に commit しない。
4. FXのトリガー（毎朝データ更新／週次再パブリッシュ）は `session_01FTxtTx…` に紐づく
   persistent セッションで動く。**動画系トリガーとは別セッション**なので文脈も混ざらない。
5. 引き継ぎ先が決まったら、FXブランチ・`fx/` フォルダ・FXトリガー2本・persistent
   セッションを**そのまま**引き渡せる（他事業に依存していないため、切り出しは容易）。

## 動画事業（雑学）の混在防止（別掲）
- 詳細は `docs/組織分離_チャンネルスコープ.md`。
- 二段ガード: **チャンネルガード**（世界の雑学王以外へは投稿しない）＋
  **ジャンル・フリーストップ**（`sleep` 等 別チャンネルのジャンルは1円も使わず停止）。

## 要確認（申し送り）
- **FactSpark（ショート）のチャンネル整合**: このトリガーは `env_01H7…`（現在は睡眠トークン）
  で動くため、`video-automation` 側に独自のチャンネルガード/独自認証が無いと、ショートが
  意図しないチャンネルへ行く恐れがある。雑学ショートを**世界の雑学王**へ確実に出すには、
  FactSpark 側にもチャンネルガードを入れるか、雑学用環境（sekai）へ寄せる要検討。

---
*目的: 雑学 / FactSpark / FX/ゴールド / 睡眠 の各事業を、ブランチとフォルダで恒久的に

引き継ぎ先が決まるまで、雑学とは分離したまま当管理者が継続管理する。*
