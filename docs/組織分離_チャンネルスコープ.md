# 組織分離・チャンネルスコープ（重要・必読）

> このリポジトリ/自動化と「睡眠チャンネル」は **別組織として管理** します。
> 相互に混ぜない・跨がない。以下は人にもエージェント（トリガー実行セッション含む）にも
> 必ず守ってほしい境界の定義です。

## この自動化の対象（スコープ内）
- **投稿先チャンネル: 「世界の雑学王」だけ。** これ以外へは投稿しない。
- ジャンル: 雑学 / 宇宙・科学 / 都市伝説 / 未解決事件・ミステリー（＋その予告編ショート、FactSparkショート）。
- 実行環境: **`env_01H7uhc6h1orRGcTsuMNsppf`**（`env_01H7…ppf`）。
- リポジトリ:
  - 長尺: `todoapp_1` ブランチ `claude/web-automation-setup-ifetgk`（`pipeline/`）
  - ショート: `video-automation`（`generator/`, FactSpark）
- 外部流入: このチャンネル用のThreads運用（`social_promote.py`）。

## スコープ外（触らない）
- **「睡眠チャンネル」（例: 睡眠・安眠チャンネル2）は別組織。** 別のGoogle Cloudプロジェクト・
  別のOAuthクライアント・別の実行環境・別の認証情報で管理される。
- こちらの自動化・トリガー・環境変数から、睡眠チャンネルへ投稿したり設定を触ったりしない。
- 睡眠チャンネル側では、その範囲で別途管理・周知済み。

## 認証の鉄則（取り違え防止）
- `env_01H7` の `YOUTUBE_CLIENT_ID / SECRET / REFRESH_TOKEN` は **必ず「世界の雑学王」** の
  認可であること（3点一致・同一クライアント由来）。
- **トークン再発行時は、必ず「世界の雑学王」のGoogleアカウントでログイン**して発行する。
  睡眠チャンネルのアカウントでログインすると、この環境が睡眠チャンネルを指してしまう。
- 睡眠チャンネル用のトークンは **睡眠用の環境にだけ** 入れる。2つを入れ替えない。

## 仕組みで担保している安全装置
1. **チャンネルガード（コード）**: `config.EXPECTED_CHANNEL_TITLE = "世界の雑学王"`。
   `youtube_upload.check_auth()` と `upload_video()` が、認証されたチャンネル名を検査し、
   期待と違えば `WrongChannelError` で **アップロード前に停止**する（誤投稿しない）。
   名称ゆらぎ対応で env `YOUTUBE_EXPECTED_CHANNEL` で上書き可。
2. **毎日ヘルスチェック**（12:40 JST）: 認証チャンネル名が「世界の雑学王」でなければ
   🚨 として push/メール通知する。
3. トリガーは生成前に `--check-auth` を通し、チャンネル不一致なら動画を作らず中断。

## 迷ったときの判断（エージェント向け）
- `--check-auth` や `channels.list(mine=true)` の結果が「世界の雑学王」以外だったら、
  **絶対に生成・投稿を進めない**。中断してユーザーに「トークンが別チャンネルを指している」
  と報告する。
- 睡眠チャンネルに関する作業依頼がこの環境/リポジトリに来ても、**スコープ外**として扱い、
  別組織側で対応する旨を案内する。
