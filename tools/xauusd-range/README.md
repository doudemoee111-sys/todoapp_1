# XAU/USD デイリーレンジ予測

金（スポット XAU/USD）の日次の高値・安値レンジを、確率付きで予測するツール。

## 何を出すか / 出さないか

**出さない**：高値・安値のピンポイント予測。日足の高安は経路依存かつ単一ニュースで決まるため、
再現性のあるエッジは存在しません。

**出す**：指定した被覆率（50/70/80/90%）の高安レンジ、想定値幅の分位点、高安の形成時刻分布、
主要節目、イベント注記。ウォークフォワード検証済みの的中率付き。

### 検証結果（名目80%箱の実測被覆率）

| 年 | 2018 | 2019 | 2020 | 2021 | 2022 | 2023 | 2024 | 2025 | 2026 |
|---|---|---|---|---|---|---|---|---|---|
| 被覆率 | 83.4% | 77.5% | 79.2% | 82.9% | 79.8% | 79.8% | 79.2% | 76.7% | 82.3% |

直近250セッション 83.6%。全年 76.7〜83.4%。

**重要**：80%箱の幅は現在約$190で、平均的な1日はその44%しか使いません。
エントリー根拠ではなく「この外側で逆張りしない」線として使うこと。

## 設計

- **セッション定義**：NY 17:00クローズ基準。米国の夏時間は `zoneinfo` が自動処理するため、
  JST表記は冬 07:00 / 夏 06:00 に自然に切り替わる。固定のJST区切りは使わない。
- **ボラ推定**：真の値幅のEWMA（半減期20日）。日中値幅の平均は2017年$12.7→2026年$120.3と
  10倍に拡大しており、10年等重み平均は使用不可。
- **分布**：正規分布を仮定せず、直近レジーム加重（半減期500日）の経験分位点。
  右裾が厚いため正規分布では下側を必ず過小評価する。
- **較正**：高値側・安値側を独立と仮定せず、同時被覆確率を実データで二分探索して解く。
- **検証**：すべてウォークフォワード。day *t* の予測は *t* 以降のデータを一切使わない。

## 業者別の日足区切り（重要）

日足の高値・安値は**業者のサーバー時間で決まる**ため、同じ日付でも業者によって別の数字になります。

| 方式 | 業者 | サーバー時間 | バー切替（JST） | レポート生成可能時刻 |
|---|---|---|---|---|
| `nyclose` | Axiory など大半のMT4/MT5業者 | GMT+2 / +3（米DST追随） | 冬 07:00 / 夏 06:00 | 07:00 JST以降 |
| `utc` | Exness | GMT+0 固定・DSTなし | 通年 09:00 | **09:00 JST以降** |

```bash
python3 daily_report.py --convention nyclose   # Axiory
python3 daily_report.py --convention utc       # Exness
python3 daily_report.py --convention both      # 両方（セッション途中の確認用）
```

### 実測した乖離（同一データ・2,541セッション）

| | 10年通算 | 直近250セッション |
|---|---|---|
| 高値が一致 | 81.3% | — |
| 安値が一致 | 83.8% | — |
| **高安とも一致** | **68.0%** | **54.0%** |
| \|高値差\| 90%点 | $1.39 | $11.18 |
| \|高値差\| 最大 | $177.86 | $177.86 |

乖離は **07:00〜09:00 JST の2時間帯**に集中します（両方式が共有しない唯一の時間帯）。
ここは高安形成確率のピーク時間と重なるため、ボラが高い局面では差が大きく出ます。
例：2026/11/02 の安値は `nyclose` 3869.06 / `utc` 3890.91 で $21.85 の差。

**`utc` 方式は 09:00 JST より前にレポートを作れません。** 前セッションの終値が
09:00 JST に確定するためです。Axiory用（07:38 JST）とExness用（09:08 JST）は
別実行にする必要があります。

### 業者設定の実測検証（MT4）

Web上のサーバー時間情報は業者の変更で古くなるため、**自分の口座のバーで確定させる**。

```bash
python3 calibrate_broker.py axiory_xauusd_d1.csv --name Axiory
python3 calibrate_broker.py exness_xauusd_d1.csv --name Exness
```

各区切りで参照日足を作り、業者のD1高安を再現できる方を選ぶ。フィードの定数オフセットは
高安を同じだけずらすので、区切りの判定前に中央値で除去しており、オフセットと区切りが
交絡しない。自己テストでは `utc` 境界・+$0.42オフセットの合成データを
一致率100%（対抗 `nyclose` は66.7%）で判定し、オフセットを +0.421 と復元した。

**MT4からのエクスポート**：F2（ヒストリーセンター）→ Metals → XAUUSD → Daily (1440)
→ エクスポート。または日足チャートで Home キーを押して履歴を読み込み、ファイル → 名前を付けて保存。
90日以上あると確度が上がる（両区切りは約68%の日で一致するため、判別は残りの約32%が担う）。

### 確認状況

| 業者 | 区切り | 根拠 |
|---|---|---|
| Axiory MT4 | `nyclose` | **公式FAQで確定**（MT4表示はGMT、夏GMT+3／冬GMT+2。スワップ付与もサーバー0時） |
| Exness MT4 | `utc` | MT4/MT5で差があるという情報はなく両方GMT+0。2026年10月のMQL5実測監査（62件すべて+0:00）が最有力 |

**保留リスク（2027年3月以降）**：Exnessの夏時間対応について情報が矛盾している。
2022年のFAQは「DSTに追随する」、2026年の複数ソースは「通年UTC固定」。
現在は冬時間でどちらでも GMT+0 なので差は出ないが、**2027年3月中旬に再検証が必要**。
追随していれば夏の区切りは 01:00 UTC = 10:00 JST になる。
`calibrate_broker.py` を夏時間期のデータで回せば判定できる。

## bid / ask

当データは **bid**。MT4/MT5のチャートもbid表示なので一致します。ただし買いの決済・逆指値は
**ask** で約定するため、上側は実効的に `高値 + スプレッド` になります。
業者のゴールドのスプレッドを加味してください。

## データ

| 用途 | ソース |
|---|---|
| 1時間足（完了月） | Dukascopy 月次ローソク足 `/{SYM}/{年}/{月-1}/BID_candles_hour_1.bi5` |
| 1時間足（当月） | Dukascopy 時間別ティック `/{SYM}/{年}/{月-1}/{日}/{時}h_ticks.bi5`（当月は月次が未publish） |
| 経済指標 | 外為どっとコム経済カレンダー（JST表記・★重要度）。robots.txt上許可範囲 |

バイナリ形式：LZMA圧縮、24バイト/レコード `>5if` = (秒オフセット, 始値, 終値, 安値, 高値, 出来高)、
価格は1000倍のint32。ティックは20バイト `>iiiff`。

## 使い方

```bash
pip install -r requirements.txt
python3 daily_report.py              # データ更新してレポート生成
python3 daily_report.py --no-update  # ディスク上のデータを再利用
```

初回は10年分（約120リクエスト、数分）。以降は差分のみ。
出力は `reports/XAUUSD_<YYYYMMDD>.md`。

## モジュール

| ファイル | 役割 |
|---|---|
| `duka.py` | Dukascopyローダー、NY区切り日足の生成 |
| `recent.py` | 当月分をティックから再構成 |

| `calendar_jp.py` | 経済指標カレンダー |
| `daily_report.py` | 統合してMarkdownレポートを生成 |

## 既知の制約

1. **フィード差**：Dukascopyのbid。業者間でヒゲが数ドル〜十数ドル違う。
2. **22:00 UTC** はロールオーバー休止でフィードが歯抜け（高安への影響は軽微）。
3. **セッション途中**に実行した場合、データ終端は実時刻より1〜2時間遅れる。
   経過時間はデータ範囲から導出しており、実時刻は使っていない。
4. カレンダーはHTML解析のため、サイト構造変更で壊れる可能性がある。

本ツールは定量分析であり、投資助言ではありません。
