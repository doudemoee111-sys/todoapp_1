# XAU/USD デイリーレンジ予測

金（スポット XAU/USD）の日次の高値・安値レンジを、確率付きで予測するツール。

## 何を出すか / 出さないか

**出さない**：高値・安値のピンポイント予測。日足の高安は経路依存かつ単一ニュースで決まるため、
再現性のあるエッジは存在しません。

**出す**：指定した被覆率（50/70/80/90%）の高安レンジ、想定値幅の分位点、高安の形成時刻分布、
主要節目、イベント注記。ウォークフォワード検証済みの的中率付き。

### 検証結果（名目80%箱の実測被覆率）

| 年 | 2018 | 2019 | 2020 | 2021 | 2022 | 2023 | 2024 | 2025 | 2026 |
|---|---|---|---|---|---|---|---|---|---|
| 被覆率 | 83.4% | 77.5% | 79.2% | 82.9% | 79.8% | 79.8% | 79.2% | 76.7% | 82.3% |

直近250セッション 83.6%。全年 76.7〜83.4%。

**重要**：80%箱の幅は現在約$190で、平均的な1日はその44%しか使いません。
エントリー根拠ではなく「この外側で逆張りしない」線として使うこと。

## 設計

- **セッション定義**：NY 17:00クローズ基準。米国の夏時間は `zoneinfo` が自動処理するため、
  JST表記は冬 07:00 / 夏 06:00 に自然に切り替わる。固定のJST区切りは使わない。
- **ボラ推定**：真の値幅のEWMA（半減期20日）。日中値幅の平均は2017年$12.7→2026年$120.3と
  10倍に拡大しており、10年等重み平均は使用不可。
- **分布**：正規分布を仮定せず、直近レジーム加重（半減期500日）の経験分位点。
  右裾が厚いため正規分布では下側を必ず過小評価する。
- **較正**：高値側・安値側を独立と仮定せず、同時被覆確率を実データで二分探索して解く。
- **検証**：すべてウォークフォワード。day *t* の予測は *t* 以降のデータを一切使わない。

## データ

| 用途 | ソース |
|---|---|
| 1時間足（完了月） | Dukascopy 月次ローソク足 `/{SYM}/{年}/{月-1}/BID_candles_hour_1.bi5` |
| 1時間足（当月） | Dukascopy 時間別ティック `/{SYM}/{年}/{月-1}/{日}/{時}h_ticks.bi5`（当月は月次が未publish） |
| 経済指標 | 外為どっとコム経済カレンダー（JST表記・★重要度）。robots.txt上許可範囲 |

バイナリ形式：LZMA圧縮、24バイト/レコード `>5if` = (秒オフセット, 始値, 終値, 安値, 高値, 出来高)、
価格は1000倍のint32。ティックは20バイト `>iiiff`。

## 使い方

```bash
pip install -r requirements.txt
python3 daily_report.py              # データ更新してレポート生成
python3 daily_report.py --no-update  # ディスク上のデータを再利用
```

初回は10年分（約120リクエスト、数分）。以降は差分のみ。
出力は `reports/XAUUSD_<YYYYMMDD>.md`。

## モジュール

| ファイル | 役割 |
|---|---|
| `duka.py` | Dukascopyローダー、NY区切り日足の生成 |
| `recent.py` | 当月分をティックから再構成 |
| `update.py` | 差分更新（完了月はキャッシュ、当月のみ再取得） |
| `build_daily.py` | 実セッションのみの日足系列（週末ダミー・祝日を除去） |
| `range_model.py` | σ推定、加重分位点、ウォークフォワード検証 |
| `forecast.py` | 同時被覆較正済みの予測箱、ピボット |
| `intraday_stats.py` | 高安の形成時刻分布、アジア時間の寄与 |
| `calendar_jp.py` | 経済指標カレンダー |
| `daily_report.py` | 統合してMarkdownレポートを生成 |

## 既知の制約

1. **フィード差**：Dukascopyのbid。業者間でヒゲが数ドル〜十数ドル違う。
2. **22:00 UTC** はロールオーバー休止でフィードが歯抜け（高安への影響は軽微）。
3. **セッション途中**に実行した場合、データ終端は実時刻より1〜2時間遅れる。
   経過時間はデータ範囲から導出しており、実時刻は使っていない。
4. カレンダーはHTML解析のため、サイト構造変更で壊れる可能性がある。

本ツールは定量分析であり、投資助言ではありません。
