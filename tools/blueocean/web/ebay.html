Shopee用に切り替える

STEP 01探す

国内の仕入れ元を、条件を決めて採ってきます。巡回（スクレイピング）はしません。楽天・Yahoo!・Amazonが公式に出している検索APIを、あなた自身が発行した鍵で叩きます。重量を返すのはAmazonだけなので、鍵が取れるならJANで突合して実測を持ってこられます。

先に鍵を取ってください（1回だけ・無料）
  1. 楽天市場 — 楽天ウェブサービス に楽天会員でログインし、アプリIDを発行。環境変数 RAKUTEN_APP_ID に入れます。1秒に1回までという制限があるので、数千件を採るときは時間がかかります。
  2. Yahoo!ショッピング — Yahoo!デベロッパーネットワーク でアプリケーションを登録し、Client ID を発行。環境変数 YAHOO_CLIENT_ID に入れます。JANコードが返るので、同じ商品を店をまたいで束ねられます。
  3. Amazon.co.jp（任意・条件が厳しい） — Amazonアソシエイト の審査に通ったうえで Creators API の client_id / client_secret を発行し、パートナータグと合わせて AMAZON_CREATORS_CREDS に id:secret:tag の形で入れます。旧 PA-API 5.0 は2026年5月15日に停止済みで、AWS署名の古い方式はもう通りません。

鍵はこの画面には入れません。ブラウザから他社のAPIは叩けない（CORSで弾かれる）ので、実際の取得はお使いのPCのコマンドで行います。ここは条件を組み立てて、そのコマンドを出すところです。

商用利用の可否や規約は各社の条件に従ってください。楽天のAPIはアフィリエイト用途を前提に無償提供されているもので、Yahoo!は商用利用について問い合わせ窓口が用意されています。自分の仕入れ判断のための価格照会として使う範囲を超える場合は、各社に確認してから使ってください。

Amazonの鍵は取れないかもしれません。アソシエイトの審査に通り、紹介売上を出し続けないと維持できないためです（開設180日以内に3件、維持に直近30日で10件程度という報告があります）。仕入リサーチだけの利用では条件を満たしにくいので、取れなくても楽天とYahoo!だけで回るように作ってあります。

STEP 02選ぶ

  
仕入値を入れると、送料・課金重量・仕入上限・利益率・判定が同じ行に出ます。行をクリックすると、その判定になった理由と、あと何を動かせば判定が変わるかが下に出ます。


  

    判定の読み方（4つしかありません）
    

      
    
        
  • 出せる — 目標利益率を満たし、競合が少なく、需要の裏付けがある。仕入れてよい。
    • 
        
  • 小さく試す — 条件のどれかが未確定。1〜2点だけ出して反応を見る段階。仕入値・重量が推定のままだとここで止まります。
    • 
        
  • 採算割れ — 仕入値が上限を超えている。いくら下げれば届くかを右端に出します。
    • 
        
  • 見送り — 競合が多すぎる。値下げ競争に入るので取らない。
    • 
        
  • 除外 — 規制品、重量・寸法オーバー、相場が未入力など、判定以前で止まっているもの。
    • 
      

      
競合0件は「出せる」になりません。誰も出していないのは、需要が無いだけかもしれないからです。落札実績を実際に見て「需要の裏付け」に yes を入れたときだけ上がります。

    それぞれの数字が何に効くのか
    

      
    
        
  • 為替 — 仕入も送料も円、売上はドル。1円動くと利益がそのまま動きます。③出す では「何円まで下がると赤字か」も出しています。
    • 
        
  • 目標利益率 — 仕入上限の逆算に使います。ここを上げると仕入上限が下がり、判定が厳しくなります。
    • 
        
  • 販売手数料 — 落札手数料・決済手数料・為替手数料を合わせた実効値です。eBayは18%前後、Shopeeは各国5.3〜7.0%に為替と送金を足して8%を既定にしています。
    • 
        
  • 関税 — セラーが負担するぶん。eBay の DDP では売り手負担、Shopee は原則購入者負担なので0です。
    • 
        
  • セラーレベル — eBayのみ。Top Rated で −2pt、Below Standard で +6pt 手数料が動きます。
    • 
        
  • 課税事業者 — 輸出は消費税が免税なので、税込で仕入れた分の 10/110 が還付されます。免税事業者だとこれが無く、同じ商品でも利益が1割近く変わります。
    • 
      

    

  


  

    
この端末に保存されているもの

    
商品の一覧・観測データ・設定は、この端末のブラウザにだけ保存されます。どこにも送信されません。ブラウザのデータを消すと一緒に消えるので、大事なものは②選ぶ の「CSVで書き出す」で手元に残してください。

    

      
    

  






  
使い方

  
上のタブは作業の順番で並んでいます。①から④へ進むだけです。


  

    
1周の流れ

    

      画面やること終わった状態

      
①探す条件を決めてコマンドを出し、PCで実行してCSVを読み込む②に商品が並んでいる

      
②選ぶ相場と競合数を埋め、判定を見る「出せる」が何件か分かっている

      
③出す売価を決める。束ねたほうが得かを見る出品価格が決まっている

      
④追う毎週レポートを貼る伸ばす／直す／畳む が決まっている

    

  


  

    
最初の1回だけ必要なこと

    

      やることどこでなぜ

      
古物商許可を取る所轄の警察署中古品を仕入れて売るなら必須。着手前に取ること

      
楽天のアプリIDを取る楽天ウェブサービス①探す で国内の仕入れ元を採るため

      
Yahoo!のClient IDを取るYahoo!デベロッパーネットワーク同上。JANが返るので同じ商品を束ねられる

      
AmazonのCreators API（任意）Amazonアソシエイト重量と寸法が取れる唯一の経路。ただし審査と売上実績の維持が要るので、取れなくても楽天とYahoo!で回る

      
Pythonを入れるお使いのPCブラウザから他社APIは叩けないため、取得はコマンドで行う

    

  


  

    
やらないことを決めてあります

    
    
      
  • 国内ECの巡回（スクレイピング）はしません。公式APIしか叩きません。
    • 
      
  • 小売サイトからバイヤーへの直送はしません。eBayの Retail Dropshipping 禁止に触れます。必ず自宅で受け取り、検品して、梱包し直してから送ります。
    • 
      
  • 相場は落札済みを見ます。出品中の価格は「まだ売れていない価格」です。
    • 
      
  • 推測で埋めた数字は推測だと言います。重量が推定のまま「出せる」判定になることはありません。
