Blue Ocean 仕入判断ツール

競合が少なく採算の合う商品を選び（軸1）、出品後の反応から有在庫化を判断する（軸2）。 リポジトリのPython版と同じ計算式をブラウザで動かします。入力はこのページから出ず、保存もされません。

前提条件（市場・手数料・関税・為替）

入力

仕入価格を空にすると上限だけを計算します。

関税率は必ず確認してください。米国の制度はこの半年で3回変わりました （de minimis廃止 → 最高裁の違法判決 → 通商法122条 → 301条）。 既定値は2026年8月時点の対日12.5%です。
仕入上限（税込）—目標利益率を満たす上限
必要な 売価÷仕入—この倍率を切る商品は見送る

損益の内訳

市場を変えるとどうなるか

市場手数料関税必要倍率

同じ商品でも売り先を変えるだけで難易度が変わります。米国一本足にしない理由がここにあります。

国内の仕入候補を貼り付けると、採算と競合環境から5段階で判定します。1行目は見出しのまま残してください。 market_price_usd と competitor_count は Terapeak 等で調べた値を入れます。

候補（CSV）

出品後の反応を貼り付けると、有在庫化・価格見直し・撤退のいずれかを判定します。 eBay Seller Hub のレポートから views / watchers / sold を持ってくる想定です。

観測（CSV）

Python版と同じ計算式を実装しています（テスト32件）。 コード：tools/blueocean

本ツールの既定値は2026年8月時点の調査に基づく前提です。収益を保証するものではありません。 関税・手数料・プラットフォーム規約は変更されます。運用前に必ず最新情報をご確認ください。 中古品を扱う場合は古物商許可が、消費税還付には課税事業者の届出が必要です。
