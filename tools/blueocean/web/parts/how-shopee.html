使い方

上のタブは作業の順番で並んでいます。①から④へ進むだけです。eBay用ツールとは、送料・関税・単価の前提が違います。

1周の流れ

画面やること終わった状態
①探す条件を決めてコマンドを出し、PCで実行してCSVを読み込む②に商品が並んでいる
②選ぶ相場と競合数を埋め、判定を見る「出せる」が何件か分かっている
③出す枠を見て、入れる数を決め、一括出品CSVを作る枠に収まる形で出品CSVができている
④追う毎週の数字を貼り、価格差を確認する止める／値上げ／値下げ が決まっている

eBay用ツールとの違い

eBay用Shopee用（このツール）
国際送料セラー負担（原価に乗る）SLSが処理。セラーは国内送料のみ
関税DDPでセラー負担原則 購入者負担（0%）
売価の下限$30$8（プチプラの新品が主戦場）
出品数実質的な上限なし500〜1,000点（台湾は500）／無在庫は約100点
③出す の中身値決め・セット販売枠の管理・一括出品・価格差の確認

この違いを無視して eBay の感覚のまま計算すると、Shopee のプチプラ帯が全部「赤字」に見えます。実際には国際送料が原価に乗らないので、そこが利益になります。

やらないことを決めてあります

  • 国内ECの巡回（スクレイピング）はしません。公式APIしか叩きません。
  • 「数千品を一括出品」は、枠の上限があるのでそのままはできません。新規開店は500〜1,000点、無在庫は約100点です。このツールは枠に収まる形で選び直すところまでをやります。
  • 無在庫を薄く広げるほどペナルティの危険が増えます。キャンセルと発送遅延がポイントの主因で、3点超で検索順位が下がります。
  • 推測で埋めた数字は推測だと言います。重量が推定のまま「出せる」判定になることはありません。重量を返すのは Amazon の Creators API だけなので、鍵が取れない間は推定のままになります。
