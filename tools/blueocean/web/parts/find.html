STEP 01探す

国内の仕入れ元を、条件を決めて採ってきます。巡回（スクレイピング）はしません。楽天・Yahoo!・Amazonが公式に出している検索APIを、あなた自身が発行した鍵で叩きます。重量を返すのはAmazonだけなので、鍵が取れるならJANで突合して実測を持ってこられます。

先に鍵を取ってください（1回だけ・無料）
  1. 楽天市場 — 楽天ウェブサービス に楽天会員でログインし、アプリIDを発行。環境変数 RAKUTEN_APP_ID に入れます。1秒に1回までという制限があるので、数千件を採るときは時間がかかります。
  2. Yahoo!ショッピング — Yahoo!デベロッパーネットワーク でアプリケーションを登録し、Client ID を発行。環境変数 YAHOO_CLIENT_ID に入れます。JANコードが返るので、同じ商品を店をまたいで束ねられます。
  3. Amazon.co.jp（任意・条件が厳しい） — Amazonアソシエイト の審査に通ったうえで Creators API の client_id / client_secret を発行し、パートナータグと合わせて AMAZON_CREATORS_CREDS に id:secret:tag の形で入れます。旧 PA-API 5.0 は2026年5月15日に停止済みで、AWS署名の古い方式はもう通りません。

鍵はこの画面には入れません。ブラウザから他社のAPIは叩けない（CORSで弾かれる）ので、実際の取得はお使いのPCのコマンドで行います。ここは条件を組み立てて、そのコマンドを出すところです。

商用利用の可否や規約は各社の条件に従ってください。楽天のAPIはアフィリエイト用途を前提に無償提供されているもので、Yahoo!は商用利用について問い合わせ窓口が用意されています。自分の仕入れ判断のための価格照会として使う範囲を超える場合は、各社に確認してから使ってください。

Amazonの鍵は取れないかもしれません。アソシエイトの審査に通り、紹介売上を出し続けないと維持できないためです（開設180日以内に3件、維持に直近30日で10件程度という報告があります）。仕入リサーチだけの利用では条件を満たしにくいので、取れなくても楽天とYahoo!だけで回るように作ってあります。
