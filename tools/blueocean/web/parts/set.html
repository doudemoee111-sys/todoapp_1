設定

ここで決めた条件を、4つの画面すべてが使います。同じ数字をどこかでもう一度入れる必要はありません。変えたら「計算し直す」を押してください。

販売の前提空欄にすると販売先ごとの既定値に戻ります

それぞれの数字が何に効くのか
  • 為替 — 仕入も送料も円、売上はドル。1円動くと利益がそのまま動きます。③出す では「何円まで下がると赤字か」も出しています。
  • 目標利益率 — 仕入上限の逆算に使います。ここを上げると仕入上限が下がり、判定が厳しくなります。
  • 販売手数料 — 落札手数料・決済手数料・為替手数料を合わせた実効値です。eBayは18%前後、Shopeeは各国5.3〜7.0%に為替と送金を足して8%を既定にしています。
  • 関税 — セラーが負担するぶん。eBay の DDP では売り手負担、Shopee は原則購入者負担なので0です。
  • セラーレベル — eBayのみ。Top Rated で −2pt、Below Standard で +6pt 手数料が動きます。
  • 課税事業者 — 輸出は消費税が免税なので、税込で仕入れた分の 10/110 が還付されます。免税事業者だとこれが無く、同じ商品でも利益が1割近く変わります。

この端末に保存されているもの

商品の一覧・観測データ・設定は、この端末のブラウザにだけ保存されます。どこにも送信されません。ブラウザのデータを消すと一緒に消えるので、大事なものは②選ぶ の「CSVで書き出す」で手元に残してください。
