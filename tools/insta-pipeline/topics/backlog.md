# ネタ在庫

書式: `- [曜日タグ] 題材`

- 曜日タグは `config.json` の `post.formatRotation` のキー（mon/tue/wed/thu/fri/sat/sun）。
- その日の型に合うネタが優先的に選ばれます。タグ無しはどの曜日にも使えます。
- 投稿済みは `out/_used-topics.json` に記録され、自動でスキップされます。
- その曜日の在庫が切れると、AIがその型に合うネタを14件だけ自動補充します。
